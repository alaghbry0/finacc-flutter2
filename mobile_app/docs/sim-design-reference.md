### 2.2 الخطوط (Cairo — مثبت منذ V3)

- العنوان الرئيسي: 20sp/700 أزرق.
- تسمية التبويب: 13–14sp/600 (نشط أزرق + مؤشر سفلي 2–3dp، خامل `#757575`).
- اسم العميل بالصف: 15–16sp/700. رقم المستند: 13sp رمادي.
- المبلغ الرئيسي: 16sp/700. المبلغ الفرعي: 13sp `#757575`.
- نص الشارة: 11–12sp/500.
- نص FAB: 14sp/600 أبيض.
- **الأرقام الجدولية**: NotoSansArabic (tnum) — قاعدة DS-18n قائمة.

### 2.3 الفراغات والأنصاف

- حواف أفقية 14–16dp · حشو الصف 12dp عمودي.
- أنصاف الأقطار: شارة 12dp · رقاقة الوقت 4dp · كبسولة FAB كاملة (28dp).
- ارتفاع الترويسة ~56dp · التبويبات ~48dp · شريط التصفية ~48dp · شريط الشهر ~52dp.

## 3. مكتبة المكونات القياسية

### 3.1 ترويسة SIM (لقطة 043857)
هامبرغر (أقصى اليمين RTL — يفتح الدرج) + العنوان أزرق عريض + **ثلاثة
أزرار أيقونية بتسميات صغيرة تحتها** (الإعدادات ⚙ / تحديث ⟳ / أشعارات 🔔
بنقطة حمراء). العنوان = اسم التطبيق أو المنشأة.

### 3.2 شريط التبويبات الأفقي
تمرير أفقي + مؤشر سفلي أزرق للنشط + **زر تبديل عرض شبكي/قائمة** بطرفه
(خلفية `#ECEFF1`). مجموعات التبويبات المرصودة بالتطبيق الأصلي متعددة
حسب الفرع (بيع/عروض/مشتريات/قبض/صرف/تقارير…) — تبويباتنا الستة منذ V3
تغطي المجموعة الأساسية.

### 3.3 شريط التصفية والبحث
قائمة منسدلة حالة («جميع ▾») يميناً + ثلاثة أيقونات يساراً (قمع · فرز ·
بحث). البحث **مضمّن** يكشفه شريط ثانٍ بحقل نصي كامل العرض.

### 3.4 رقاقة النطاق الزمني + شريط الشهر
رقاقة زرقاء فاتحة بحد `#81D4FA` وخلفية `#E1F5FE` (نص `#0277BD`) ثم
شريط رمادي `#ECEFF1`: يمينه رابط «عرض جميع فواتير الشهر» أزرق،
ويساره اسم الشهر + **الإجمالي بأسود عريض** (أو أخضر teal).

### 3.5 صف المعاملة (توقيع SIM البصري)
كتلة تاريخ (يوم كبير 14sp/700 فوق شهر صغير 11sp رمادي) + اسم الطرف
عريض + رقم المستند رمادي + **شارة حالة ملونة** + المبلغ الرئيسي عريض
يساراً والمتبقي تحته رمادياً. فاصل 1px `#F0F0F0`.

### 3.6 كبسولة FAB
`centerFloat` — زرقاء كاملة الاستدارة، أيقونة + والأيقونة **يمين النص**،
نص «إنشاء فاتورة/إضافة فاتورة» أبيض عريض، ظل 6dp.

### 3.7 الدرج الجانبي (لقطة 044105)
عرض ~304dp أبيض · ترويسة `#F5F5F5` بارتفاع ~160dp فيها 3 أزرار دائرية
(إعدادات/تحديث/تنبيه بنقطة حمراء) + أيقونة تقارير كبيرة · شبكة 3×3
(فاتورة · نقدي · فواتير / إشعار · المشتريات · عميل / مساعدة · مسودة
وعرض · إعدادات — لقطة 044057) · قائمة بنود بارتفاع 56dp (أيقونة +
تسمية + شيفرون توسيع) بفواصل · ذيل بزرّي قفل مميزين.

### 3.8 محرر الفاتورة (V4 — لقطة 062621)
ترويسة INV بخط 22sp/700 + تاريخ قابل للتغيير + منتقي عميل بشيفرون ·
شريط «إجمالي عناصر» **أزرق** قابل للطي · بنود بحقول (كمية بخلفية
`#E3F2FD` · سعر · وصف · مرجع اختياري) وزر إضافة عنصر · أكورديونات
(خصم والقروض · ضريبة القيمة) · شريط «مجموع» **داكن `#546E7A`** أبيض ·
شريط سفلي (حفظ · إرسال · طباعة · أكثر).

## 4. تدفقات التفاعل (من JavaScript النموذج)

- `switchMainTab` — تبديل التبويب يعيد تحميل القائمة ويصفر التصفية.
- `setStatusFilter` / `setTimeFilter` / `sortInvoices` — قوائم منسدلة/صفوف
  خيارات ثم انعاش فوري للقائمة والشريط الشهري.
- `toggleSearchBar` — كشف/إخفاء حقل البحث المضمّن مع تفريغ الاستعلام.
- `handleFabClick` — من تبويب الفواتير يفتح نموذج فاتورة جديدة.
- `openScreen` — التنقل بين الشاشات السبع مع حفظ حالة القائمة الرئيسية.
- `toggleAccordion` / `toggleSublist` — أكورديونات النموذج والدرج.
- `saveFinalInvoice` — حفظ ← توست نجاح ← عودة للقائمة بالبند الجديد
  بشارته.
- `applyPaymentToInvoice` / `payFullInvoiceNow` — سداد كامل/جزئي من
  تفاصيل الفاتورة.

## 5. بروتوكول التحقق الحي (إلزامي بعد كل جولة واجهات)

1. بناء الويب (`scripts/build-flutter-web.sh`) ثم فتح الجذر `:81/`.
2. **مقارنة بصرية** مع لقطات المرجع (نفس البنية والألوان والشارات).
3. تفاعل CDP لمسي حقيقي (cdp-touch — أحداث الفأرة لا تصل لكانفس
   Flutter): تمرير القائمة، فتح الدرج، تبديل تبويب، كشف البحث.
4. لقطة إثبات إلى `download/` + صفر أخطاء كونسول.
