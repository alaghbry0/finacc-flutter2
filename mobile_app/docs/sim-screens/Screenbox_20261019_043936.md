### Critical Implementation Notes for Flutter:

1. **Directionality:** Wrap entire scaffold in `Directionality(textDirection: TextDirection.rtl, ...)`
2. **Font:** Use `GoogleFonts.cairo()` or similar for authentic Arabic rendering
3. **Number Formatting:** Note that numbers appear in English/Latin numerals (264,000) not Arabic (٢٦٤,٠٠٠) - this is common in financial apps for alignment
4. **Mixed Text:** The client name "My Father73" is LTR text inside RTL context - ensure `textDirection` handling doesn't break alignment
5. **Status Logic:** The yellow badge suggests a "Pending" state. Implement as a `Chip` with `backgroundColor: Color(0xFFFFF8E1)` and `side: BorderSide(color: Color(0xFFFFD54F))`
6. **Scroll Behavior:** The month summary strip should be `SliverAppBar` or `sticky` header while list scrolls beneath it
7. **FAB Location:** In RTL, FAB typically stays bottom-center or moves slightly left. Screenshot shows exact center.
