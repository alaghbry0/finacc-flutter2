### 1. Screen Identity & User Flow
*   **Screen Name:** Invoice List / Dashboard (قائمة الفواتير)
*   **Purpose:** Primary hub for viewing, filtering, and managing client invoices.
*   **User Flow Step:** This is the **Home/Root Screen (Step 1)** of the application. It serves as the central navigation point from which users can view financial summaries, filter by status, and initiate the creation of new invoices via the FAB.

### Implementation Notes for Flutter Developer:
1.  **Directionality:** Wrap the entire scaffold in `Directionality(textDirection: TextDirection.rtl, ...)`.
2.  **Font:** Use `GoogleFonts.cairo()` or `GoogleFonts.tajawal()` for authentic Arabic rendering.
3.  **Dropdown:** Use `showMenu` or a `Stack` with `Positioned` widget for the custom-styled dropdown to match the shadow/border radius exactly.
4.  **FAB:** Use `FloatingActionButton.extended` with `shape: StadiumBorder()` for the pill shape.
5.  **Overflow:** The tab bar appears to use a `ListView` or `TabBar(isScrollable: true)` to handle overflow of tabs.
