Here is the exhaustive, pixel-perfect UI/UX analysis of the **"Simple Invoice Manager" (مدير الفواتير البسيط)** Android app screen. This spec is designed for a 1:1 Flutter rebuild.

---

### **1. Screen Name & User Flow**
*   **Screen Name:** Invoice List / Dashboard (قائمة الفواتير)
*   **Purpose:** To display a filtered list of invoices for a specific client ("حسن بيط"), showing itemized details, subtotals, and final payment summaries.
*   **User Flow Step:** This is the **"Client Detail / Filtered View"** step. The user has navigated from the main dashboard into a specific client's transaction history or applied a client-based filter.

### **6. List Item Structure (Detailed)**

Each item follows a **"Label : Value"** pattern aligned to opposite edges (Justified):

*   **Standard Item:**
    *   `[Flex End/Right]`: Title Text (e.g., "كريس")
    *   `[Flex Start/Left]`: Empty or Value
    *   **Padding:** Horizontal 16dp, Vertical 12dp.
    *   **Divider:** 1px line at bottom.

*   **Complex Item (Expanded):**
    *   Contains a sub-grid for `1300.00` and `1.00`.
    *   Includes a descriptive subtitle in smaller font.

*   **Collapsible Summary Row:**
    *   `[Right]`: Label (e.g., "خصم والضريبة")
    *   `[Center-Left]`: Context Icon (Gear)
    *   `[Left]`: Current Value (e.g., "(+) 0.00 $")
    *   `[Far Left]`: Expand Chevron

### **7. Cards, Chips, and Special Components**

*   **FAB (Floating Action Button):**
    *   **Shape:** Rectangle with rounded top-right corner (or full rounded rectangle cut off by screen edge). Actually looks like a **vertical tab** attached to the left side.
    *   **Unique Feature:** The text **"إضافة صنف"** is written vertically alongside the icon.
*   **Month/Summary Strips:**
    *   These are not cards but **full-width horizontal bars** with distinct background colors to create visual hierarchy separating the list from the totals.
*   **Input Fields:**
    *   The row with **"صافي"** and **"٥"** resembles a text field with an underline border, suggesting it might be editable inline.
