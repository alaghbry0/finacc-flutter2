**UI/UX Analysis: Simple Invoice Manager (Arabic RTL) – "Invoices" Screen**

This is a comprehensive, pixel-perfect specification for cloning the provided Android screen. The interface follows Material Design 2/3 principles adapted for Arabic RTL (Right-to-Left) layout.

---

### **1. Screen Identity & User Flow**
*   **Screen Name:** Invoices List / Dashboard (شاشة الفواتير)
*   **Purpose:** Central hub for managing client invoices, viewing financial summaries (paid/unpaid), and navigating to sub-modules like estimates and delivery notes.
*   **User Flow Step:** This is the **primary landing screen** after login or the main dashboard of the app. It represents the "Browse & Manage" phase of the invoice lifecycle.
*   **Context:** The user is currently filtered to view invoices for **"May" (أيوٴ)** (5th month), as indicated by the active tab.

### **6. List Item Structure (Detailed Breakdown)**

Each row in the main list follows this **Flex/Row layout** (RTL):

```
[Left: Chevron Icon] [Left-Center: Amount/Meta Text] ... [Spacer] ... [Right-Center: Title Text] [Right: Contextual Icon]
```

**Example (Row 2):**
*   **Left:** `∨` (24dp icon)
*   **Mid-Left:** "12,700.00 $ (+)" (Aligned to left, padding 16dp)
*   **Mid-Right:** "إجمالي عروض *" (Aligned to right, padding 16dp)
*   **Right:** 🛒 Cart Icon (24dp, padding 16dp)

**Summary Cards (Non-expandable):**
*   Full-width background color (Gray or Blue-Gray).
*   No chevrons.
*   **Bold** text for both label (right) and value (left).
*   Height: ~48dp fixed.

*   **Chips/Tags:** None visible in this view.

### **8. Spacing & Visual Details**

*   **Padding (Horizontal):** 16dp standard for all list items.
*   **Padding (Vertical):** 12-16dp between items.
*   **Dividers:** 1px height, `#E0E0E0`, full width (or inset 16dp if following Material, but here looks full-width).
*   **Corner Radius:** 
    *   FAB/Plus buttons: Circular (50% radius).
    *   Summary cards: 0dp (sharp corners) or very slight 2dp.
    *   Bottom nav: 0dp (sharp top corners).
*   **Shadows:**
    *   App bar: Elevation 4dp (shadow visible at bottom).
    *   Bottom nav: Elevation 8dp (shadow visible at top).
    *   List items: No elevation (flat).
*   **Borders:** Only the divider lines; no visible borders on cards or buttons (rely on background color contrast).

### **Implementation Notes for Flutter Developer:**

1.  **Directionality:** Wrap the entire scaffold in `Directionality(textDirection: TextDirection.rtl, ...)`.
2.  **ExpansionTile:** Use `ExpansionTile` for the chevron rows. Customize the trailing icon position (it will automatically move to left in RTL).
3.  **The "Hybrid" Summary Rows:** The gray/blue rows are not expansion tiles but simple `Container`s with `Row(children: [Text('مجموع'), Spacer(), Text('12,700.00 $')])`.
4.  **The Blue Header:** This is likely a `ThemeData` override for an `ExpansionTile` or a custom `ListTile` with a blue `Container` background and white text.
5.  **Inline FABs:** For the rows with `+` buttons, use a `Row` with `MainAxisAlignment.spaceBetween`. The button is a `CircleAvatar` with `backgroundColor: primaryBlue` and `child: Icon(Icons.add, color: white)`. Stack the "إضافة" text below it using a `Column`.
6.  **BottomNav:** Use `BottomNavigationBar` with `type: BottomNavigationBarType.fixed`, `selectedFontSize: 12`, `unselectedFontSize: 12`, and `selectedItemColor: primaryBlue`.

This spec should enable a 1:1 pixel-perfect reconstruction in Flutter.
