### Implementation Notes for Flutter Developer:

1.  **RTL Directionality:** Wrap the entire scaffold in `Directionality(textDirection: TextDirection.rtl, ...)`. This automatically flips the Flex layouts.
2.  **CustomScrollView/SliverAppBar:** Use this to handle the collapsing behavior if needed, though this looks like a simple `ListView` with `Expanded` sections.
3.  **The Square FAB:** Implement using a `Container` with `BoxDecoration` positioned with a `Stack` overlapping the blue `Container` above it by ~28px (half height). Use `Transform.rotate` or `writingMode` for vertical text if not using a `Column` with `mainAxisSize: MainAxisSize.min`.
4.  **Input Decoration:** Use `OutlineInputBorder` with `borderRadius: BorderRadius.circular(4)` and `borderSide: BorderSide(color: Colors.grey[300])`. For the quantity field, change `filled: true` and `fillColor: Colors.blue[50]`.
5.  **Expandable Tiles:** Use `ExpansionTile` or custom `AnimatedCrossFade` for the discount/tax sections. The chevrons should rotate 180deg on expansion.
6.  **Font:** Ensure you load an Arabic-capable font like 'Cairo' or 'Tajawal' in your `pubspec.yaml` to match the clean sans-serif look.
