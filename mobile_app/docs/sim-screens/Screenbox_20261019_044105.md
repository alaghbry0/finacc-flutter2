### 1. Screen Purpose & Context
This is the **primary navigation drawer** of an Arabic-RTL invoice management application. It serves as the main entry point for users to switch between functional modules (Invoices, Clients, Products, Expenses, etc.). The drawer is currently open, overlaying the main "Invoice List" screen (partially visible in the background). This represents **Step 0** in the user flow—the structural backbone of the app's information architecture.

### Critical Implementation Notes for Flutter Cloning:

1.  **RTL Directionality:** Wrap entire scaffold in `Directionality(textDirection: TextDirection.rtl, ...)`
2.  **Drawer Implementation:** Use `Drawer` widget with `ListView` containing `ListTile` widgets customized with `trailing: Icon(Icons.keyboard_arrow_down)`
3.  **Badge System:** Use `Stack` for the notification dots on icons; position with `Positioned(top: 0, right: 0)`
4.  **Bottom Sticky Footer:** In the ListView, use `Column` with `Expanded` for the list and fixed-height `Container` for the bottom buttons, OR use `CustomScrollView` with `SliverFillRemaining` and `hasScrollBody: false`
5.  **Font Priority:** Ensure Arabic font supports proper shaping (use `GoogleFonts.cairo()` or similar)
6.  **Elevation:** Set drawer `elevation: 16`
7.  **Active State Logic:** The POS item (13) shows special badging logic—implement conditional rendering for locked/premium features
