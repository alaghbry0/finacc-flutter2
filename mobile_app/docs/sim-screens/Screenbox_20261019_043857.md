### 1. Screen Identity & User Flow
*   **Screen Name:** Invoice List / Dashboard (قائمة الفواتير)
*   **Purpose:** Primary landing screen displaying a chronological list of invoices with filtering, search, and summary capabilities.
*   **User Flow Step:** This is the **Home/Root screen (Step 1)** of the main application flow. From here, users can navigate to create new invoices, view details, or access settings.

### Implementation Notes for Flutter Developer

1.  **Directionality:** Wrap entire scaffold in `Directionality(textDirection: TextDirection.rtl, child: ...)`.
2.  **Scroll Behavior:** The list should be scrollable, but the App Bar, Tabs, Filter Bar, and Month Strip should remain pinned (use `CustomScrollView` with `SliverAppBar` or `NestedScrollView`).
3.  **FAB Position:** Use `floatingActionButtonLocation: FloatingActionButtonLocation.centerFloat`.
4.  **Font:** Ensure Arabic font supports proper shaping (use `GoogleFonts.cairo()` or `GoogleFonts.tajawal()`).
5.  **Status Logic:** The badge "المتبقي للتحصيل" suggests this invoice has a partial payment or is overdue. The color coding (Amber) indicates "Warning/Pending" state.
6.  **Date Handling:** The date "October 2026" appears in English/Latin script despite Arabic UI, suggesting either system locale mixing or specific design choice. Preserve as shown.
