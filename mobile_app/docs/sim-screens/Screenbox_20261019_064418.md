**UI/UX Analysis Report: Simple Invoice Manager (Arabic RTL)**
**Screen:** Invoice Creation / Client Selection Form (Step 1 of 2)
**User Flow:** New Invoice Entry → Client Association

---

### 1. Screen Identity & Purpose
This is the **"Select Existing or Create New Client"** screen within the invoice creation workflow. It represents the initial data entry step where the user must associate an invoice with a client entity before proceeding to line-item details. The interface uses a **Right-to-Left (RTL)** layout optimized for Arabic.

### Implementation Notes for Flutter Cloning:

1.  **Directionality:** Wrap entire scaffold in `Directionality(textDirection: TextDirection.rtl, ...)`
2.  **Scaffold Structure:** Use `AppBar` for header, `Column` with `Expanded` containing `ListView` or `SingleChildScrollView` for middle, and `BottomAppBar` or fixed `Container` for footer buttons.
3.  **Input Fields:** Use `TextFormField` wrapped in `Container` with `decoration: BoxDecoration(color: Color(0xFFE8EFF5))`. The label should be positioned above using `InputDecoration(labelText:)` or a separate `Text` widget with proper alignment.
4.  **Buttons:** Use `ElevatedButton` for primary (blue fill) and `OutlinedButton` for secondary (white with blue border). Set `style: ElevatedButton.styleFrom(minimumSize: Size(double.infinity, 48))` and place in `Row` with `MainAxisAlignment.spaceBetween`.
5.  **Font:** Ensure Arabic font support (use `GoogleFonts.cairo()` or `GoogleFonts.tajawal()` for authentic appearance).
6.  **Responsive:** The footer buttons should use `Expanded` or `Flexible` widgets to maintain the ~55/40 width ratio across different screen sizes while maintaining the ~12dp gap between them.
