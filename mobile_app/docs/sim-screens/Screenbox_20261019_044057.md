**UI/UX Analysis Report: Simple Invoice Manager (Arabic RTL)**
**Screen State:** Navigation Drawer (Side Menu) - Open Overlay
**User Flow Step:** Global Navigation / Feature Access Layer

---

### 1. Screen Name & Purpose
This is the **Main Navigation Drawer** (Side Menu) of "Simple Invoice Manager" (`مدير الفواتير البسيط`). It serves as the primary navigation hub, allowing users to switch between core modules (Invoices, Clients, Products), access settings, and manage cloud synchronization. The drawer is overlaid on top of the main invoice list screen (visible in background).

### Implementation Notes for Flutter Cloning:

1.  **RTL Directionality:** Wrap entire scaffold in `Directionality(textDirection: TextDirection.rtl, ...)`
2.  **Drawer Implementation:** Use `Drawer` widget or `EndDrawer` (since it opens from right in RTL) with `ListView` containing `ExpansionTile` widgets for the menu items.
3.  **Grid:** Use `GridView.count(crossAxisCount: 3, childAspectRatio: 1.2, ...)` for the quick actions.
4.  **Badges:** Use `Stack` with `Positioned` for the orange notification badges on shield icons.
5.  **Selected State:** Use `Container(color: Colors.blue[50])` wrapped around the active list tile.
6.  **Shadows:** Use `BoxShadow` with `color: Colors.black26`, `blurRadius: 4`, `offset: Offset(0, 2)`.
7.  **Fonts:** Use Google Fonts package with 'Cairo' or 'Tajawal' for authentic Arabic rendering.

This spec provides pixel-perfect parameters for exact visual reconstruction.
