     1→/// محرك ترحيل فاتورة الشراء الذرّي — جداول `invoice` (doc_type='purchase') /
     2→/// `invoice_item` / `batch` / `stock_level` / `stock_movement` / `cash_tx` /
     3→/// `payment_allocation` — المرحلة 5 (FR-02-08 / قاعدة 5.4-3 / AC-03).
     4→///
     5→/// **الخريطة الملزمة** (قاعدة 5.4-4 + ملحق و): الحفظ = (رقم PUR ذرّي +
     6→/// الفاتورة + بنودها بتكلفة الوحدة الفعلية بعد توزيع خصم الرأس pro-rata +
     7→/// **تحديث WAC** + إنشاء الدفعات الواردة + زيادة المخزون وحركاته + حركة
     8→/// الصندوق للجزء النقدي + تخصيص المدفوع + قيد التدقيق) داخل **Transaction
     9→/// واحدة** — فشل أي خطوة يرجع الكل (AC-09-أ).
    10→///
    11→/// خطوط حمراء مطبَّقة هنا:
    12→/// - **WAC بالعملة الأساسية** (قاعدة 5.4-3 + تعليق المخطط على
    13→///   `product.cost_price`): خصم الرأس يوزَّع pro-rata على البنود **قبل**
    14→///   تحديث WAC، ثم `unitCostBase = round4(netFinal × سعر يوم الشراء ÷
    15→///   المستلم الكلي)` ثم
    16→///   `new_cost = (qty_old×cost_old + qty_new×cost_new)/(qty_old+qty_new)`؛
    17→///   وعند `qty_old ≤ 0` تُعتمد `cost_new` مباشرة (AC-03: شراء 10 @100
    18→///   بخصم رأس 10% → التكلفة 90 لا 100).
    19→/// - **بونص الشراء** (R16-a — قرار المالك الموثّق، مرآة «المنصرف
    20→///   الكلي» للبيع): المستلم الكلي = `qty + free_qty` — الدفعة الواردة
    21→///   و`stock_level` وحركة المخزون وWAC كلها على الكلي، و**WAC = إجمالي
    22→///   التكلفة ÷ المستلم الكلي** فالبونص يخفّض التكلفة الوحدوية حرفياً
    23→///   (شراء 10+2 مجاني بتكلفة 1200 → دفعة 12 وحدة بوحدة تكلفة 100).
    24→///   المورد يُستحق من `qty` المدفوعة حصراً (subtotal/total/due_amount
    25→///   بلا أي أثر للبونص) — فلا تضخيم لدين المورد، و`line_cost` =
    26→///   المستلم الكلي × تكلفة الوحدة الفعلية (قيمة المخزون الوارد).
    27→/// - **فصل العملات** (5.4-7): الفاتورة وسندها النقدي وتخصيصها كلها بعملة
    28→///   الفاتورة وسعر يومها (Snapshot FR-08-05)؛ الأساس يُخزَّن في `total_base`
    29→///   و`line_cost`/`cost_total` (بالعملة الأساسية — نفس اصطلاح البيع).
    30→/// - **سياسة FX المفقود** (FR-08-09 / AC-13): عملة غير أساس بلا سعر اليوم
    31→///   → رفض، إلا إذا فُعّل `fx.fallback=last_known` فيُستخدم آخر سعر مع
    32→///   `rate_is_fallback=1` (شارة FR-02-20) — نفس نمط `sale_repository`.
    33→/// - **اتجاه الصندوق معاكس للبيع** (ملحق و: شراء نقدي CASH → INV): الجزء
    34→///   النقدي سند **صرف** (`tx_type='payment'`) من الصندوق الافتراضي، لا
    35→///   قبض.
    36→///
    37→/// ## قرارات موثقة (انظر worklog-parts/7-b.md للتفصيل):
    38→/// 1. **qty_old لصيغة WAC** = Σ(`stock_level.qty`) للصنف **عبر كل
    39→///    المخازن** داخل المعاملة — التقييم (`product.cost_price`) عالميّ
    40→///    للصنف لا لكل مخزن، فالمتوسط المرجّح يُحسب على المخزون الكلي.
    41→///    والأسطر المتكررة لنفس الصنف تُحدَّث تتابعياً داخل المعاملة نفسها
    42→///    (يُكافئ رياضياً دمجها في تحديث واحد).
    43→/// 2. **الجزء الآجل** (`remainingCredit`) دين للمورد في `invoice.due_amount`
    44→///    حصراً — صيغة رصيد المورد (FR-03-03) تقرأه منه. سند الصرف المصاحب
    45→///    يُكتب بـ `supplier_id = NULL` حتى لا تخصمه صيغة الرصيد (التي تطرح
    46→///    سندات الصرف المرتبطة بالمورد) مرتين — مرآة القرار 2 في
    47→///    `sale_repository`.
    48→/// 3. **payment_allocation** يوثّق الجزء المدفوع نقداً وقت الإصدار (سند
    49→///    الصرف ← الفاتورة) — نفس اصطلاح البيع؛ العمود `cash_tx_id` NOT NULL
    50→///    فلا تخصيص للجزء الآجل بلا سند.
    51→/// 4. **الدفعات الواردة** (FR-01-10): صنف متتبع + رقم دفعة + صلاحية →
    52→///    صف `batch` جديد بتكلفة الوحدة الفعلية **بالعملة الأساسية** (داخل
    53→///    المعاملة مباشرة — `BatchRepository.createBatch` يكتب خارج المعاملة
    54→///    فلا يصلح هنا؛ طلب نسخة تقبل txn مسجَّل للمنسّق). الصنف المتتبع **بلا
    55→///    دفعة** يضاف للمخزون العام بلا دفعة (وفق التكليف) — **تنبيه موثَّق**:
    56→///    فحص توفر البيع للمتتبعين يعدّ الدفعات النشطة فقط، فهذا الرصيد بلا
    57→///    دفعة لا يظهر متاحاً للبيع حتى شراء لاحق بدفعة؛ الواجهة يجب أن تُلزم
    58→///    رقم الدفعة للأصناف المتتبعة. الصنف غير المتتبع مع رقم دفعة → رفض.
    59→/// 5. **رقم فاتورة المورد الورقي** (`supplierInvoiceRef`): لا عمود له في
    60→///    المخطط المجمد — يُخزَّن كبادئة موثَّقة داخل `notes_internal` بصيغة
    61→///    «فاتورة المورد: <الرقم>» (طلب عمود مخصص مسجَّل للمنسّق).
    62→/// 6. **لا دفع زائد**: الشراء لا يعرف «الباقي» — `paidCash` محصور بين
    63→///    0 والصافي (رفض واضح بخلاف البيع الذي يعيد الباقي للعميل).
    64→/// 7. **الأصناف الخدمية** (FR-01-16): تدخل فاتورة الشراء بلا مخزون ولا
    65→///    دفعات ولا WAC — `line_cost = 0` (كلفتها مصروف مستقبلي خارج V1).
    66→/// 8. **المسودة (draft)** خارج نطاق هذا المحرك — البناء للمكتملة فقط
    67→///    (`status='completed'` وفق آلة الحالات 5.4-2).
    68→/// 9. **الضريبة** 0% في V1 لهذا المحرك (`tax_rate=0`) — الأعمدة جاهزة
    69→///    بالمخطط ووحدة الضريبة لاحقة.

   110→/// مستودع المشتريات — ترحيل PUR الذرّي وقراءات فواتير الشراء.
   111→class PurchaseRepository {
   112→  /// يبنى فوق قاعدة مفتوحة؛ يركّب المستودعات الشريكة (تواقيعها ملزمة)
   113→  /// فوق نفس القاعدة دون إعادة إنشاء.
   114→  PurchaseRepository(Database db)
   115→    : _db = db,
   116→      _rates = ExchangeRateRepository(db),
   117→      _settings = SettingsRepository(db);
   118→
   119→  final Database _db;
   120→  final ExchangeRateRepository _rates;
   121→  final SettingsRepository _settings;
   122→
   123→  // ─────────────────────────────────────────────────────────────────────
   124→  // الترحيل الذرّي (FR-02-08 / 5.4-3 / 5.4-4)
   125→  // ─────────────────────────────────────────────────────────────────────
   126→
   127→  /// **ترحيل فاتورة شراء مكتملة** — معاملة واحدة (انظر رأس الملف
   128→  /// للخريطة).
   129→  ///
   130→  /// [userId] منفّذ العملية (يُخزَّن في created_by والتدقيق).
   131→  /// [now] لحظة الكتابة الفعلية (created_at/updated_at/audit) — تاريخ
   132→  /// العمل `draft.issuedAt` وحده يحدد سنة الترقيم وسعر الصرف.
   133→  ///
   134→  /// الترتيب: تحقّق نقّي → تحميلات مسبقة (عملة/سياسة FX/أصناف/مورد/
   135→  /// صندوق) → معاملة واحدة (رقم ← فاتورة ← بنود + WAC + دفعات واردة +
   136→  /// مخزون ← نقدي ← تخصيص ← تدقيق) → إيصال.
   137→  Future<Result<PurchasePostedReceipt, String>> postPurchase(
   138→    PurchaseDraft draft, {
   139→    required int userId,
   140→    DateTime? now,
   141→  }) async {
   142→    final at = now ?? DateTime.now();
   143→    final issuedAt = draft.issuedAt;
   144→    final issuedIso = issuedAt.toUtc().toIso8601String();
   145→
   146→    // (1) التسعير والتحقق النقي (خصومات/كميات/دفع/دفعات واردة) — قبل
   147→    //     أي كتابة.
   148→    final cartFailure = PurchasePricing.validateCart(
   149→      draft.lines,
   150→      invoiceDiscountType: draft.invoiceDiscountType,
   151→      invoiceDiscountValue: draft.invoiceDiscountValue,
   152→    );
   153→    if (cartFailure != null) return Err(cartFailure);
   154→    final priced = PurchasePricing.priceCart(
   155→      draft.lines,
   156→      invoiceDiscountType: draft.invoiceDiscountType,
   157→      invoiceDiscountValue: draft.invoiceDiscountValue,
   158→    );
   159→    final totals = priced.totals;
   160→    final payFailure = PurchasePricing.validatePayment(
   161→      totals.grandTotal,
   162→      draft.paidCash,
   163→      draft.paymentMethod,
   164→    );
   165→    if (payFailure != null) return Err(payFailure);
   166→    final settlement = PurchasePricing.settlePayment(
   167→      totals.grandTotal,
   168→      draft.paidCash,
   169→    );
   170→    final netPaid = settlement.netPaid;
   171→    final remainingCredit = settlement.remainingCredit;
   172→    final payStatus = settlement.payStatus;
   173→
   174→    try {
   175→      // (2) العملة + سياسة FX (FR-08-09) — قراءة خارج المعاملة (نمط
   176→      //     البيع حرفياً).
   177→      final currency = await _db.query(
   178→        'currency',
   179→        columns: ['id', 'code', 'is_base'],
   180→        where: 'id = ?',
   181→        whereArgs: [draft.currencyId],
   182→        limit: 1,
   183→      );
   184→      if (currency.isEmpty) {
   185→        return Err('العملة رقم #${draft.currencyId} غير موجودة.');
   186→      }
   187→      final isBase = (currency.first['is_base'] as int? ?? 0) == 1;
   188→      final currencyCode = currency.first['code'] as String;
   189→      var exchangeRate = 1.0;
   190→      var rateIsFallback = false;
   191→      if (!isBase) {
   192→        final todayRate = await _rates.rateFor(draft.currencyId, issuedAt);
   193→        if (todayRate != null && todayRate > 0) {
   194→          exchangeRate = todayRate;
   195→        } else {
   196→          final fallbackOn =
   197→              (await _settings.getString('fx.fallback', 'off')) == 'last_known';
   198→          if (!fallbackOn) {
   199→            return Err(
   200→              'لا يوجد سعر صرف لعملة $currencyCode بتاريخ اليوم — '
   201→              'أدخل سعر اليوم أولاً ثم احفظ (لا يُحفظ بسعر افتراضي).',
   202→            );
   203→          }
   204→          final lastKnown = await _rates.latestBefore(
   205→            draft.currencyId,
   206→            issuedAt,
   207→          );
   208→          if (lastKnown == null || lastKnown <= 0) {
   209→            return Err(
   210→              'لا يوجد أي سعر صرف معروف لعملة $currencyCode — '
   211→              'أدخل سعراً واحداً على الأقل قبل الشراء بها.',
   212→            );
   213→          }
   214→          exchangeRate = lastKnown;
   215→          rateIsFallback = true; // شارة «سعر صرف تقديري» (FR-02-20).
   216→        }
   217→      }
   218→
   219→      // (3) الأصناف — تحميل واحد مجمّع + رفض المفقود/المؤرشف + فحص
   220→      //     حقول الدفعة الواردة مقابل تتبع الصنف (القرار 4).
   221→      final productIds = draft.lines.map((l) => l.productId).toSet();
   222→      final products = await _loadProducts(productIds);
   223→      for (var i = 0; i < draft.lines.length; i++) {
   224→        final line = draft.lines[i];
   225→        final info = products[line.productId];
   226→        if (info == null) {
   227→          return Err('الصنف رقم #${line.productId} غير موجود.');
   228→        }
   229→        if (info.isArchived) {
   230→          return Err('الصنف «${info.name}» مؤرشف — لا يُشترى (FR-01-15).');
   231→        }
   232→        final batchNo = line.batchNo?.trim() ?? '';
   233→        if (batchNo.isNotEmpty && !info.trackBatches) {
   234→          return Err(
   235→            'الصنف «${info.name}» لا يتتبع الدفعات — احذف رقم الدفعة '
   236→            '«$batchNo» من البند ${i + 1} أو فعّل تتبع الدفعات للصنف.',
   237→          );
   238→        }
   239→      }
   240→
   241→      // (4) المورد (إلزامي للشراء) — وجود + عدم أرشفة.
   242→      final supplierRows = await _db.query(
   243→        'supplier',
   244→        columns: ['name', 'is_archived'],
   245→        where: 'id = ?',
   246→        whereArgs: [draft.supplierId],
   247→        limit: 1,
   248→      );
   249→      if (supplierRows.isEmpty) {
   250→        return Err('المورد رقم #${draft.supplierId} غير موجود.');
   251→      }
   252→      if ((supplierRows.first['is_archived'] as int? ?? 0) == 1) {
   253→        return Err(
   254→          'المورد «${supplierRows.first['name']}» مؤرشف — أزل الأرشفة '
   255→          'أولاً أو اختر مورداً آخر.',
   256→        );
   257→      }
   258→
   259→      // (5) الصندوق الافتراضي للمنشأة — للجزء النقدي فقط.
   260→      int? cashboxId;
   261→      if (netPaid > moneyEpsilon) {
   262→        final boxRows = await _db.query(
   263→          'cashbox',
   264→          columns: ['id'],
   265→          where: 'is_default = 1 AND is_archived = 0',
   266→          limit: 1,
   267→        );
   268→        if (boxRows.isEmpty) {
   269→          return Err('لا يوجد صندوق افتراضي للمنشأة — أنشئ صندوقاً أولاً.');
   270→        }
   271→        cashboxId = boxRows.first['id'] as int;
   272→      }
   273→
   274→      // (6) المعاملة الواحدة — كل الكتابات أو لا شيء (5.4-4).
   275→      return await _db.transaction((txn) async {
   276→        // 6-أ) رقم PUR ذرّي داخل المعاملة نفسها (قاعدة 5.4-1).
   277→        final year = issuedAt.year; // سنة يوم العمل المحلية.
   278→        final seq = DocSequenceService(txn);
   279→        final number = await seq.nextNumber(DocSequenceType.purchase, year);
   280→        final docNo = formatDocNumber(DocSequenceType.purchase, year, number);
   281→
   282→        // 6-ب) رأس الفاتورة (كل الأعمدة وفق §5.3) — رقم فاتورة المورد
   283→        //      الورقي كبادئة موثَّقة داخل الملاحظة الداخلية (القرار 5).
   284→        final totalBase = roundCost(totals.grandTotal * exchangeRate);
   285→        final notesInternal = _composeInternalNotes(
   286→          draft.supplierInvoiceRef,
   287→          draft.notesInternal,
   288→        );
   289→        final invoiceId = await txn.insert('invoice', {
   290→          'invoice_no': docNo,
   291→          'doc_type': 'purchase',
   292→          'pay_status': payStatus.code,
   293→          'status': 'completed',
   294→          'issued_at': issuedIso,
   295→          'supplier_id': draft.supplierId,
   296→          'cashbox_id': cashboxId,
   297→          'warehouse_id': draft.warehouseId,
   298→          'currency_id': draft.currencyId,
   299→          'exchange_rate': exchangeRate,
   300→          'rate_is_fallback': rateIsFallback ? 1 : 0,
   301→          'subtotal': totals.subtotal,
   302→          'discount_amount': roundMoney(totals.totalDiscount),
   303→          'tax_rate': 0,
   304→          'tax_amount': 0,
   305→          'total': totals.grandTotal,
   306→          'total_base': totalBase,
   307→          'paid_amount': netPaid,
   308→          'due_amount': remainingCredit,
   309→          'cost_total': 0, // يُجمَّع من الأسطر ثم يُحدَّث أدناه.
   310→          'notes_internal': notesInternal,
   311→          'notes_printed': draft.notesPrinted,
   312→          'created_at': at.toUtc().toIso8601String(),
   313→          'updated_at': at.toUtc().toIso8601String(),
   314→          'created_by': userId,
   315→        });
   316→
   317→        // 6-ج) الأسطر: تكلفة الوحدة الفعلية بالعملة الأساسية ÷ المستلم
   318→        //      الكلي (بونص R16-a) → WAC → الدفعة الواردة → السطر →
   319→        //      المخزون وحركته — سطراً سطراً.
   320→        var costTotal = 0.0;
   321→        for (final pricedLine in priced.lines) {
   322→          final info = products[pricedLine.line.productId]!;
   323→          final lineQty = pricedLine.line.qty;
   324→          // المستلم الكلي (بونص R16-a): المدفوع + المجاني يدخلان المخزون
   325→          // معاً — > 0 دائماً لأن qty > 0 مُتحقَّق في PurchasePricing.
   326→          final freeQty = pricedLine.line.freeQty;
   327→          final receivedQty = lineQty + freeQty;
   328→
   329→          // تكلفة الوحدة الفعلية بالعملة الأساسية بسعر يوم الشراء (AC-03)
   330→          // — **بالقسمة على المستلم الكلي** (قرار تحاسبي موثّق R16-a:
   331→          // إجمالي التكلفة ÷ إجمالي الكمية المستلمة — البونص يخفّض
   332→          // التكلفة الوحدوية: 10+2 مجاني بتكلفة 1200 → 100)؛ الخدمي بلا
   333→          // تكلفة مخزونية (القرار 7).
   334→          final unitCostBase = info.isService
   335→              ? 0.0
   336→              : roundCost(pricedLine.netFinal * exchangeRate / receivedQty);
   337→          final lineCost = roundCost(receivedQty * unitCostBase);
   338→          costTotal = roundCost(costTotal + lineCost);
   339→
   340→          // WAC (5.4-3): يُقرأ ويُحدَّث داخل المعاملة على المستلم الكلي —
   341→          // قلب الشراء (بونص R16-a: الكمية الجديدة بالكلي).
   342→          if (!info.isService) {
   343→            await _applyWac(
   344→              txn,
   345→              productId: info.id,
   346→              qtyNew: receivedQty,
   347→              costNew: unitCostBase,
   348→              now: at,
   349→            );
   350→          }
   351→
   352→          // الدفعة الواردة (القرار 4): متتبع + رقم + صلاحية → صف batch
   353→          // داخل المعاملة مباشرة (createBatch يكتب خارجها فلا يصلح).
   354→          // بونص R16-a: الدفعة تستقبل الكلي بتكلفة الوحدة الوحدوية.
   355→          int? batchId;
   356→          final batchNo = pricedLine.line.batchNo?.trim() ?? '';
   357→          if (!info.isService && info.trackBatches && batchNo.isNotEmpty) {
   358→            batchId = await txn.insert('batch', {
   359→              'product_id': info.id,
   360→              'warehouse_id': draft.warehouseId,
   361→              'batch_number': batchNo,
   362→              'expiry_date': _dateOnly(pricedLine.line.expiryDate!),
   363→              'cost_price': unitCostBase,
   364→              'qty': receivedQty,
   365→              'created_at': at.toUtc().toIso8601String(),
   366→              'updated_at': at.toUtc().toIso8601String(),
   367→            });
   368→          }
   369→
   370→          final lineNotes = [
   371→            if ((pricedLine.line.notes ?? '').trim().isNotEmpty)
   372→              pricedLine.line.notes!.trim(),
   373→            if (batchId != null) 'دفعة: $batchNo×${_num(receivedQty)}',
   374→            if (freeQty > _qtyEpsilon) 'بونص: ${_num(freeQty)}',
   375→          ].join(' — ');
   376→
   377→          await txn.insert('invoice_item', {
   378→            'invoice_id': invoiceId,
   379→            'product_id': info.id,
   380→            'line_desc': info.name, // لقطة اسم الصنف للعرض/الطباعة.
   381→            'qty': lineQty,
   382→            'free_qty': freeQty, // البونص مستقل (R16-a — مرآة البيع).
   383→            'unit_id': info.unitId,
   384→            'unit_factor': 1,
   385→            'unit_price': pricedLine.line.unitCost,
   386→            'discount_percent':
   387→                pricedLine.line.lineDiscountType == PurchaseDiscountType.percent
   388→                ? pricedLine.line.lineDiscountValue
   389→                : 0,
   390→            'discount_amount': pricedLine.effectiveDiscount,
   391→            'tax_percent': 0,
   392→            'line_total': pricedLine.netFinal,
   393→            'line_cost': lineCost, // بالعملة الأساسية (اصطلاح البيع).
   394→            'batch_id': batchId,
   395→            'notes': lineNotes.isEmpty ? null : lineNotes,
   396→            'created_at': at.toUtc().toIso8601String(),
   397→          });
   398→
   399→          // الخدمي: لا مخزون ولا دفعات (القرار 7).
   400→          if (info.isService) continue;
   401→
   402→          // المخزون: زيادة مباشرة بالمستلم الكلي (الشراء وارد — بونص
   403→          // R16-a يدخل المخزون كالمدفوع) + حركة واردة بتكلفة الوحدة
   404→          // الفعلية بالأساس.
   405→          await txn.rawInsert(
   406→            'INSERT OR IGNORE INTO stock_level(product_id, warehouse_id, qty) '
   407→            'VALUES(?, ?, 0)',
   408→            [info.id, draft.warehouseId],
   409→          );
   410→          await txn.rawUpdate(
   411→            'UPDATE stock_level SET qty = qty + ? '
   412→            'WHERE product_id = ? AND warehouse_id = ?',
   413→            [receivedQty, info.id, draft.warehouseId],
   414→          );
   415→          await txn.insert('stock_movement', {
   416→            'product_id': info.id,
   417→            'warehouse_id': draft.warehouseId,
   418→            'movement_type': 'purchase',
   419→            'qty': receivedQty, // الوارد الكلي موجب (بونص داخل).
   420→            'unit_cost': unitCostBase,
   421→            'ref_type': 'invoice',
   422→            'ref_id': invoiceId,
   423→            'moved_at': issuedIso,
   424→            'notes': batchId == null
   425→                ? (freeQty > _qtyEpsilon
   426→                      ? '$docNo — بونص: ${_num(freeQty)}'
   427→                      : docNo)
   428→                : '$docNo — دفعة $batchNo (تنتهي '
   429→                      '${_dateOnly(pricedLine.line.expiryDate!)})'
   430→                      '${freeQty > _qtyEpsilon ? ' — بونص: ${_num(freeQty)}' : ''}',
   431→            'created_at': at.toUtc().toIso8601String(),
   432→            'created_by': userId,
   433→          });
   434→        }
   435→
   436→        // 6-د) تجميع قيمة المخزون الوارد على رأس الفاتورة (بالأساس).
   437→        await txn.update(
   438→          'invoice',
   439→          {'cost_total': costTotal},
   440→          where: 'id = ?',
   441→          whereArgs: [invoiceId],
   442→        );
   443→
   444→        // 6-هـ) الجزء النقدي: سند **صرف** من الصندوق الافتراضي بعملة
   445→        //       الفاتورة وسعرها (اتجاه معاكس للبيع — ملحق و) + تخصيصه
   446→        //       للفاتورة (القراران 2 و3). `supplier_id = NULL` حتى لا
   447→        //       يُخصم من رصيد المورد مرتين.
   448→        if (netPaid > moneyEpsilon) {
   449→          final cashTxId = await txn.insert('cash_tx', {
   450→            'tx_type': 'payment',
   451→            'cashbox_id': cashboxId,
   452→            'currency_id': draft.currencyId,
   453→            'amount': netPaid,
   454→            'exchange_rate': exchangeRate,
   455→            'tx_date': issuedIso,
   456→            'ref_type': 'invoice',
   457→            'ref_id': invoiceId,
   458→            'supplier_id': null, // لا يُخصم من رصيد المورد (القرار 2).
   459→            'description': 'دفع نقدي عند إصدار $docNo',
   460→            'created_at': at.toUtc().toIso8601String(),
   461→            'created_by': userId,
   462→          });
   463→          await txn.insert('payment_allocation', {
   464→            'cash_tx_id': cashTxId,
   465→            'invoice_id': invoiceId,
   466→            'allocated_amount': netPaid,
   467→            'allocated_at': at.toUtc().toIso8601String(),
   468→            'created_by': userId,
   469→          });
   470→        }
   471→        // الجزء الآجل لا يُدرج في payment_allocation (لا سند له) — دينه
   472→        // في invoice.due_amount تقرأه صيغة رصيد المورد (FR-03-03).
   473→
   474→        // 6-و) قيد التدقيق (append-only — نمط المستودعات القائمة).
   475→        await txn.insert('audit_log', {
   476→          'user_id': userId,
   477→          'action': 'purchase_post',
   478→          'entity': 'invoice',
   479→          'entity_id': invoiceId,
   480→          'details':
   481→              'no=$docNo total=${totals.grandTotal} '
   482→              'paid=$netPaid due=$remainingCredit '
   483→              'currency=$currencyCode rate=$exchangeRate'
   484→              '${rateIsFallback ? ' fallback=1' : ''}',
   485→          'at': at.toUtc().toIso8601String(),
   486→        });
   487→
   488→        return Ok<PurchasePostedReceipt, String>(
   489→          PurchasePostedReceipt(
   490→            invoiceId: invoiceId,
   491→            docNo: docNo,
   492→            totals: totals,
   493→            payStatus: payStatus,
   494→            exchangeRate: exchangeRate,
   495→            rateIsFallback: rateIsFallback,
   496→            remainingCredit: remainingCredit,
   497→          ),
   498→        );
   499→      });
   500→    } on _FlowError catch (e) {
   501→      return Err(e.message);
   502→    } on StateError catch (e) {
   503→      // حراس المستودعات الشريكة — رسالتهم عربية جاهزة وتدحرج المعاملة.
   504→      return Err(e.message);
   505→    } on DatabaseException catch (e) {
   506→      return Err(_describeDbError(e));
   507→    }

   594→  /// **WAC (قاعدة 5.4-3)** — يقرأ التكلفة والكمية الكلية داخل المعاملة
   595→  /// ثم يحدّث `product.cost_price` بدقة أربع منازل:
   596→  ///
   597→  /// - `qty_old > 0`:
   598→  ///   `new = (qty_old×cost_old + qty_new×cost_new)/(qty_old + qty_new)`
   599→  /// - `qty_old ≤ 0`: `new = cost_new` مباشرة (لا متوسط على مخزون معدوم).
   600→  ///
   601→  /// `qty_old` = Σ stock_level.qty عبر كل المخازن (القرار 1 بالرأس).
   602→  Future<void> _applyWac(
   603→    DatabaseExecutor txn, {
   604→    required int productId,
   605→    required double qtyNew,
   606→    required double costNew,
   607→    required DateTime now,
   608→  }) async {
   609→    final rows = await txn.rawQuery(
   610→      'SELECT p.cost_price AS cost, '
   611→      '       COALESCE((SELECT SUM(sl.qty) FROM stock_level sl '
   612→      '                 WHERE sl.product_id = p.id), 0) AS qty '
   613→      'FROM product p WHERE p.id = ?',
   614→      [productId],
   615→    );
   616→    if (rows.isEmpty) {
   617→      throw _FlowError('الصنف رقم #$productId غير موجود.');
   618→    }
   619→    final costOld = (rows.first['cost'] as num?)?.toDouble() ?? 0;
   620→    final qtyOld = (rows.first['qty'] as num?)?.toDouble() ?? 0;
   621→    double newCost;
   622→    if (qtyOld <= _qtyEpsilon) {
   623→      newCost = costNew; // المخزون معدوم/سالب دفترياً → التكلفة الجديدة.
   624→    } else {
   625→      newCost = roundCost(
   626→        (qtyOld * costOld + qtyNew * costNew) / (qtyOld + qtyNew),
   627→      );
   628→    }
   629→    if (newCost < 0) newCost = 0; // حارس نظري (لا تكلفة سالبة).
   630→    await txn.update(
   631→      'product',
   632→      {'cost_price': newCost, 'updated_at': now.toUtc().toIso8601String()},
   633→      where: 'id = ?',
   634→      whereArgs: [productId],
   635→    );
   636→  }

   662→  static String? _composeInternalNotes(String? supplierRef, String? notes) {
   663→    final ref = supplierRef?.trim() ?? '';

   671→  /// يصوغ خطأ قاعدة البيانات بكلمات المستخدم (نمط sale_repository).
   672→  String _describeDbError(DatabaseException e) {
   673→    if (e.isUniqueConstraintError()) {
   674→      final text = e.toString();
   675→      if (text.contains('invoice_no')) {
   676→        return 'تعارض في رقم فاتورة الشراء — أعد الحفظ';
   677→      }
   678→      if (text.contains('payment_allocation')) {
   679→        return 'تخصيص مدفوعات مكرر لنفس السند والفاتورة';
   680→      }
   681→      return 'قيمة مكررة تخالف قيد التفرد في القاعدة';
   682→    }
   683→    if (_isCheckFailure(e)) {
   684→      final text = e.toString();
   685→      if (text.contains('stock_level')) {
   686→        return 'المخزون لا يسمح بهذه الكمية (رصيد سالب ممنوع)';
   687→      }
   688→      if (text.contains('due_amount') || text.contains('paid_amount')) {
   689→        return 'مبالغ الدفع غير متسقة مع إجمالي فاتورة الشراء';
   690→      }
   691→      return 'قيمة تخالف قيد سلامة محاسبي في القاعدة';
   692→    }
   693→    return 'تعذر حفظ فاتورة الشراء في القاعدة: $e';
   694→  }
   695→}

   697→/// هل الخطأ خرقاً لقيد CHECK؟ (لا مساعد جاهز في sqflite — نقرأ الرسالة).
   698→bool _isCheckFailure(DatabaseException e) =>
   699→    e.toString().toUpperCase().contains('CHECK');

   701→/// تفاوت الكميات (NUMERIC(12,3) بالمخطط).
   702→const double _qtyEpsilon = 0.000001;
   703→
   704→/// يصيغ رقماً للعرض في الرسائل بلا أصفار زائدة.
   705→String _num(double v) {
   706→  if (v.isNaN || v.isInfinite) {
   707→    return v.toString();
   708→  }
   709→  final rounded = (v * 1000).round() / 1000;
   710→  if (rounded == rounded.round()) {
   711→    return rounded.toInt().toString();
   712→  }
   713→  return rounded.toStringAsFixed(3);
   714→}
