     1→/// محرك ترحيل المرتجعات المرتبطة الذرّي — SRN (مرتجع بيع، FR-02-07) و
     2→/// PRN (مرتجع شراء، FR-02-08) — جداول `invoice` (doc_type='sale_return'/
     3→/// 'purchase_return' مع `original_invoice_id`) / `invoice_item` / `batch` /
     4→/// `stock_level` / `stock_movement` / `cash_tx` / `payment_allocation`.
     5→///
     6→/// **الخريطة الملزمة** (قاعدة 5.4-4 + ملحق و): الحفظ = (رقم SRN/PRN ذرّي +
     7→/// الفاتورة المرتبطة + بنودها بكميات وتكاليف **Snapshot من الفاتورة
     8→/// الأصلية** + حركات المخزون + حركة الصندوق للجزء النقدي + التخصيص +
     9→/// قيد التدقيق) داخل **Transaction واحدة** — فشل أي خطوة يرجع الكل.
    10→///
    11→/// خطوط حمراء مطبَّقة هنا:
    12→/// - **الارتباط الحصري** (FR-02-07): لا مرتجع حر — `original_invoice_id`
    13→///   إلزامي، والنوع يجب أن يطابق (SRN عن فاتورة بيع، PRN عن فاتورة شراء)،
    14→///   والحالة `completed` حصراً (الملغاة `void` والمسودة `draft` مرفوضتان).
    15→/// - **مرتجع البيع بتكلفة line_cost الأصلية** (قاعدة 5.4-3): الكمية تعود
    16→///   للمخزون **بالتكلفة الأصلية المنقولة** — WAC الجاري لا يُلمس إطلاقاً.
    17→/// - **مرتجع الشراء بسعر حركة الشراء الأصلية (Snapshot)** (FR-02-08): الخروج
    18→///   بتكلفة الوحدة الأصلية (`line_cost الأصلي / الكمية`) ويُعاد حساب WAC
    19→///   على المتبقي: `WAC = (qty_old×cost_old − qty_ret×cost_snapshot) /
    20→///   (qty_old − qty_ret)` مع حماية القسمة (المتبقي ≤ 0 → التكلفة 0) وعدم
    21→///   السماح بتكلفة سالبة.
    22→/// - **سقف الكميات**: مجموع مرتجعات الفاتورة ≤ المباع/المشترى لكل بند —
    23→///   يفحص قبل المعاملة ويعاد فحصه داخلها (حراسة التزامن).
    24→/// - **منع السالب المخزوني** (5.4-5): PRN يرفض ما لا يغطيه المخزون
    25→///   (stock_level للعادي، ومجموع الدفعات للمتتبع) برسالة تسمّي الصنف.
    26→///
    27→/// ## قرارات موثقة (انظر worklog-parts/7-b.md للتفصيل):
    28→/// 1. **مرجع البند الأصلي**: المخطط المجمد بلا عمود `original_item_id` في
    29→///    `invoice_item` — يُخزَّن المرجع بعلامة قياسية موثَّقة داخل عمود
    30→///    `notes` بصيغة «أصل البند #معرّف» (يكتبها ويقرؤها هذا المحرك حصراً
    31→///    بتعبير نمطي ثابت) — أساس حساب «المتبقي للإرجاع» لكل بند. طلب عمود
    32→///    مخصص مسجَّل للمنسّق.
    33→/// 2. **اتجاه المبلغ** (FR-02-07/08): `credit` = خصم من حساب الطرف عبر
    34→///    `invoice.due_amount` للمستند المرتجع — صيغتا رصيد العميل (FR-03-02)
    35→///    والمورد (FR-03-03) تطرحان `due_amount` لمستندات المرتجع تلقائياً
    36→///    فتنقصان الدين بلا أي كتابة إضافية، وكشف الحساب يظهر قيد المرتجع
    37→///    (−) صحيحاً. `cash` = رد نقدي من/إلى الصندوق (`cash_tx` باتجاه معاكس
    38→///    للفاتورة الأصلية: SRN سند **صرف** للعميل، PRN سند **قبض** من
    39→///    المورد) + **تخصيص مدفوعات عكسي** (`payment_allocation` يوثّق الجزء
    40→///    النقدي المرتجع كما يوثّق نظيره وقت الإصدار). `mixed` بينهما. سند
    41→///    SRN النقدي يُكتب بـ `customer_id = NULL` وسند PRN النقدي بـ
    42→///    `supplier_id = NULL` — مرآة اصطلاح الإصدار (لا خصم مزدوج من رصيد
    43→///    الطرف). لا رد زائد: المبلغ النقدي محصور بين 0 وقيمة المرتجع.
    44→/// 3. **الدفعات في مرتجع البيع (SRN)**: الكمية تعود إلى **دفعات الفاتورة
    45→///    الأصلية نفسها** — يُتبَّع الاستهلاك الأصلي من حركات مخزون البيع
    46→///    (`stock_movement` بحركة لكل دفعة برجوع للفاتورة، وملاحظتها تحمل
    47→///    «رقم الدفعة X (تنتهي Y)» — نفس صيغة `sale_repository` حرفياً)،
    48→///    والسعة لكل دفعة = ما استُهلك منها في البيع الأصلي − ما أُعيد إليها
    49→///    سابقاً (حركات SRN سابقة بنفس الصيغة) — فلا تتجاوز كمية أي دفعة ما
    50→///    استُهلك منها أبداً، والبنود المتعددة لنفس الصنف في مرتجع واحد
    51→///    تتقاسم السعات في الذاكرة. **أي كمية متبقية بلا دفعة قابلة للتتبع
    52→///    (دفعة مؤرشفة/محذوفة أو استهلاك غير موثَّق) تضاف للمخزون العام بلا
    53→///    دفعة** مع تعليق موثَّق في ملاحظة السطر (وفق التكليف) — ملاحظة:
    54→///    رصيد المتتبعين بلا دفعة لا يظهر متاحاً للبيع (فحص توفر البيع يعدّ
    55→///    الدفعات النشطة فقط) حتى شراء لاحق بدفعة.
    56→/// 4. **الدفعات في مرتجع الشراء (PRN)**: الخصم من **الدفعة الواردة
    57→///    الأصلية** أولاً (`invoice_item.batch_id` الذي خزّنه postPurchase لكل
    58→///    بند) ثم أي متبقٍ بدفعات الصنف النشطة FEFO (`allocateFefo` بـ
    59→///    includeExpired — إرجاع البضاعة المنتهية للمورد جائز)؛ وإن لم تكفِ
    60→///    الدفعات فالعملية **تُرفض** (المتتبع مخزونه في دفعاته — خصم بلا
    61→///    دفعة يفسد نسبة الدفعات إلى stock_level).
    62→/// 5. **عملة المرتجع وسعره**: عملة المستند المرتجع = عملة الفاتورة
    63→///    الأصلية حصراً (حتى يخصم/يرد على الرصيد الصحيح بعملته — 5.4-7)،
    64→///    وسعر صرفه يُحل وفق FR-08-09 بتاريخ إصدار المرتجع (الرفض أو
    65→///    `fx.fallback` بعلم) — **قيمة المخزون لا تُحوَّل بسعر يوم المرتجع**
    66→///    بل تُنقل من `line_cost` الأصلي (Snapshot بالعملة الأساسية).
    67→/// 6. **مبلغ المرتجع**: لكل بند — `gross = round2(qty_ret × unit_price
    68→///    الأصلي)` وخصم تناسبي `round2(qty_ret × discount_amount الأصلي /
    69→///    qty الأصلية)` فـ `line_total = gross − الخصم` — استرداد تناسبي
    70→///    تام لما دُفع فعلاً عن الوحدات المرتجعة (بما فيها نصيبها من خصم
    71→///    الرأس الموزَّع وقت الشراء/البيع المخزَّن في `discount_amount`).
    72→/// 7. **المخزن**: حركات المرتجع على مخزن الفاتورة الأصلية حصراً (حيث
    73→///    خرجت/دخلت البضاعة أصلاً).

    77→///    لم يُدفع عنه شيء أصلاً)، بينما **تكلفة الوحدة المنقولة** =
    78→///    `line_cost / (qty + free_qty)` — تكلفة الوحدة الفعلية وقت البيع

    81→///    البونص، والخارج من التكلفة عند الاسترداد يخص المدفوع المرتجع فقط.

   293→/// مستودع المرتجعات — SRN وPRN المرتبطة حصراً + بنود الإرجاع المتاحة.
   294→class ReturnRepository {
   295→  /// يبنى فوق قاعدة مفتوحة؛ يركّب المستودعات الشريكة فوق نفس القاعدة.
   296→  ReturnRepository(Database db)
   297→    : _db = db,
   298→      _rates = ExchangeRateRepository(db),
   299→      _settings = SettingsRepository(db),
   300→      _batches = BatchRepository(db);
   301→
   302→  final Database _db;
   303→  final ExchangeRateRepository _rates;
   304→  final SettingsRepository _settings;
   305→  final BatchRepository _batches;
   306→
   307→  // ───────────────────────────────────────────────────────────────────
   308→  // مرتجع البيع (SRN) — FR-02-07
   309→  // ───────────────────────────────────────────────────────────────────
   310→
   311→  /// **ترحيل مرتجع بيع مرتبط** — معاملة واحدة (انظر رأس الملف).
   312→  ///
   313→  /// الكمية تعود لمخزن الفاتورة الأصلية **بتكلفة line_cost الأصلية**
   314→  /// (لا WAC الجاري — قاعدة 5.4-3) وإلى دفعات البيع الأصلية عند تتبعها
   315→  /// (القرار 3)، والقيمة تُرد نقداً من الصندوق أو خصماً من حساب العميل
   316→  /// (القرار 2).
   317→  Future<Result<ReturnPostedReceipt, String>> postSaleReturn(
   318→    SaleReturnDraft draft, {
   319→    required int userId,
   320→    DateTime? now,
   321→  }) async {
   322→    final at = now ?? DateTime.now();
   323→    final issuedAt = draft.issuedAt;
   324→    final issuedIso = issuedAt.toUtc().toIso8601String();
   325→
   326→    // (1) تحقق نقي من البنود — قبل أي قراءة/كتابة.
   327→    final linesFailure = _validateLines(draft.lines);
   328→    if (linesFailure != null) return Err(linesFailure);
   329→
   330→    try {
   331→      // (2) الفاتورة الأصلية: نوع + حالة + وجود (FR-02-07).
   332→      final orig = await _loadOriginal(draft.originalInvoiceId, 'sale');
   333→      if (orig.error != null) return Err(orig.error!);
   334→
   335→      // (3) البنود الأصلية + المنتسب + سقف الكميات (القرار 1).
   336→      final membership = await _checkMembershipAndCaps(
   337→        draft.originalInvoiceId,
   338→        'sale_return',
   339→        draft.lines,
   340→      );
   341→      if (membership.error != null) return Err(membership.error!);
   342→      final origItems = membership.items;
   343→
   344→      // (4) قيمة المرتجع Snapshot من البنود الأصلية (القرار 6).
   345→      final valued = _valueReturnLines(origItems, draft.lines);
   346→      final refundTotal = valued.refundTotal;
   347→
   348→      // (5) اتجاه الرد مقابل الأرقام (القرار 2).
   349→      final refundFailure = _validateRefund(
   350→        refundTotal,
   351→        draft.refundCash,
   352→        draft.refundMethod,
   353→      );
   354→      if (refundFailure != null) return Err(refundFailure);
   355→      final settlement = _settleRefund(refundTotal, draft.refundCash);
   356→      final refundCash = settlement.netCash;
   357→      final refundCredit = settlement.credit;
   358→
   359→      // (6) حساب العميل للجزء المخصوم (FR-02-07: اتجاه المبلغ).
   360→      if (refundCredit > moneyEpsilon && orig.row['customer_id'] == null) {
   361→        return Err(
   362→          'الفاتورة الأصلية بلا عميل مسجَّل (بيع نقدي مجهول) — لا حساب '
   363→          'يُخصم منه؛ اختر رد القيمة نقداً من الصندوق.',
   364→        );
   365→      }
   366→
   367→      // (7) سياسة FX بعملة الفاتورة الأصلية بتاريخ المرتجع (القرار 5).
   368→      final fx = await _resolveRate(orig.row['currency_id'] as int, issuedAt);
   369→      if (fx.error != null) return Err(fx.error!);
   370→
   371→      // (8) الصندوق الافتراضي — للجزء النقدي فقط.
   372→      int? cashboxId;
   373→      if (refundCash > moneyEpsilon) {
   374→        final boxId = await _defaultCashboxId();
   375→        if (boxId == null) {
   376→          return Err('لا يوجد صندوق افتراضي للمنشأة — أنشئ صندوقاً أولاً.');
   377→        }
   378→        cashboxId = boxId;
   379→      }
   380→
   381→      // (9) معلومات الأصناف (خدمي/متتبع).
   382→      final products = await _loadProductsForItems(origItems);
   383→
   384→      // (10) المعاملة الواحدة — كل الكتابات أو لا شيء (5.4-4).
   385→      return await _db.transaction((txn) async {
   386→        // 10-أ) رقم SRN ذرّي (قاعدة 5.4-1).
   387→        final year = issuedAt.year;
   388→        final seq = DocSequenceService(txn);
   389→        final number = await seq.nextNumber(DocSequenceType.saleReturn, year);
   390→        final docNo = formatDocNumber(DocSequenceType.saleReturn, year, number);
   391→
   392→        // 10-ب) رأس المرتجع (كل الأعمدة وفق §5.3) — الارتباط الحصري.
   393→        final invoiceId = await txn.insert('invoice', {
   394→          'invoice_no': docNo,
   395→          'doc_type': 'sale_return',
   396→          'pay_status': settlement.method.code,
   397→          'status': 'completed',
   398→          'issued_at': issuedIso,
   399→          'original_invoice_id': draft.originalInvoiceId,
   400→          'customer_id': orig.row['customer_id'],
   401→          'cashbox_id': cashboxId,
   402→          'warehouse_id': orig.row['warehouse_id'],
   403→          'currency_id': orig.row['currency_id'],
   404→          'exchange_rate': fx.rate,
   405→          'rate_is_fallback': fx.isFallback ? 1 : 0,
   406→          'subtotal': valued.subtotal,
   407→          'discount_amount': valued.discountTotal,
   408→          'tax_rate': 0,
   409→          'tax_amount': 0,
   410→          'total': refundTotal,
   411→          'total_base': roundCost(refundTotal * fx.rate),
   412→          'paid_amount': refundCash,
   413→          'due_amount': refundCredit,
   414→          'cost_total': valued.costTotal,
   415→          'notes_internal': draft.notesInternal,
   416→          'notes_printed': draft.notesPrinted,
   417→          'created_at': at.toUtc().toIso8601String(),
   418→          'updated_at': at.toUtc().toIso8601String(),
   419→          'created_by': userId,
   420→        });
   421→
   422→        // 10-ج) حرارة السقف داخل المعاملة (التزامن — القرار 1).
   423→        await _assertCapsInside(
   424→          txn,
   425→          draft.originalInvoiceId,
   426→          'sale_return',
   427→          draft.lines,
   428→        );
   429→
   430→        // 10-د) البنود: تكلفة أصلية منقولة + عودة الكمية للمخزون
   431→        //       (ودفعات البيع الأصلية — القرار 3). سعات الدفعات تُحمَّل
   432→        //       مرة لكل صنف وتتقاسمها البنود في الذاكرة.
   433→        final batchCaps = <int, List<_BatchCap>>{};
   434→        for (var i = 0; i < draft.lines.length; i++) {
   435→          final input = draft.lines[i];
   436→          final origItem = origItems[input.invoiceItemId]!;
   437→          final productId = origItem['product_id'] as int?;
   438→          final info = productId == null ? null : products[productId];
   439→          final lineQty = input.qty;
   440→
   441→          // Snapshot تكلفة الوحدة الأصلية (بالعملة الأساسية) — على
   442→          // المنصرف الكلي (البونص داخل line_cost — القرار 8).
   443→          final snapshotUnit = roundCost(
   444→            (origItem['line_cost'] as num? ?? 0) / _dispatchedDivisor(origItem),
   445→          );
   446→          final lineCost = roundCost(lineQty * snapshotUnit);
   447→
   448→          // سعات دفعات الصنف (استهلاك البيع الأصلي − ما أُعيد سابقاً).
   449→          List<_BatchCap>? caps;
   450→          if (info != null && info.trackBatches && productId != null) {
   451→            var productCaps = batchCaps[productId];
   452→            if (productCaps == null) {
   453→              productCaps = await _loadBatchReturnCaps(
   454→                txn,
   455→                productId: productId,
   456→                warehouseId: orig.row['warehouse_id'] as int,
   457→                originalInvoiceId: draft.originalInvoiceId,
   458→              );
   459→              batchCaps[productId] = productCaps;
   460→            }
   461→            caps = productCaps;
   462→          }
   463→
   464→          // تخصيص عودة هذا البند على السعات.
   465→          final entries = <_BatchCap>[];
   466→          var remaining = lineQty;
   467→          if (caps != null) {
   468→            for (final cap in caps) {
   469→              if (remaining <= _qtyEpsilon) break;
   470→              if (cap.qty <= _qtyEpsilon) continue;
   471→              final take = cap.qty < remaining ? cap.qty : remaining;
   472→              entries.add(
   473→                _BatchCap(
   474→                  batchId: cap.batchId,
   475→                  batchNumber: cap.batchNumber,
   476→                  expiryDate: cap.expiryDate,
   477→                  qty: take,
   478→                ),
   479→              );
   480→              cap.qty = roundCost(cap.qty - take);
   481→              remaining = roundCost(remaining - take);
   482→            }
   483→          }
   484→          final residual = roundCost(remaining);
   485→
   486→          final batchSummary = entries.isEmpty
   487→              ? null
   488→              : entries
   489→                    .map((e) => '${e.batchNumber}×${_num(e.qty)}')
   490→                    .join('، ');
   491→          final lineNotes = [
   492→            'أصل البند #${input.invoiceItemId}',
   493→            if (batchSummary != null) 'دفعة: $batchSummary',
   494→            if (residual > _qtyEpsilon)
   495→              'مرتجع بلا دفعة (${_num(residual)} أضيف للمخزون العام)',
   496→          ].join(' — ');
   497→
   498→          await txn.insert('invoice_item', {
   499→            'invoice_id': invoiceId,
   500→            'product_id': productId,
   501→            'line_desc': origItem['line_desc'],
   502→            'qty': lineQty,
   503→            'unit_id': origItem['unit_id'],
   504→            'unit_factor': 1,
   505→            'unit_price': origItem['unit_price'],
   506→            'discount_percent': origItem['discount_percent'],
   507→            'discount_amount': valued.discounts[i],
   508→            'tax_percent': 0,
   509→            'line_total': valued.lineTotals[i],
   510→            'line_cost': lineCost, // التكلفة الأصلية منقولة (5.4-3).
   511→            'batch_id': entries.isNotEmpty ? entries.first.batchId : null,
   512→            'notes': lineNotes,
   513→            'created_at': at.toUtc().toIso8601String(),
   514→          });
   515→
   516→          // الخدمي: لا مخزون (FR-01-16).
   517→          if (info == null || info.isService || productId == null) continue;
   518→
   519→          // زيادة الدفعات + حركة لكل دفعة (القرار 3).
   520→          for (final entry in entries) {
   521→            await txn.rawUpdate(
   522→              'UPDATE batch SET qty = qty + ?, updated_at = ? WHERE id = ?',
   523→              [entry.qty, at.toUtc().toIso8601String(), entry.batchId],
   524→            );
   525→            await txn.insert('stock_movement', {
   526→              'product_id': productId,
   527→              'warehouse_id': orig.row['warehouse_id'],
   528→              'movement_type': 'sale_return',
   529→              'qty': entry.qty, // الوارد موجب.
   530→              'unit_cost': snapshotUnit,
   531→              'ref_type': 'invoice',
   532→              'ref_id': invoiceId,
   533→              'moved_at': issuedIso,
   534→              'notes':
   535→                  'رقم الدفعة ${entry.batchNumber} '
   536→                  '(تنتهي ${entry.expiryDate}) — $docNo',
   537→              'created_at': at.toUtc().toIso8601String(),
   538→              'created_by': userId,
   539→            });
   540→          }
   541→          // المتبقي بلا دفعة → مخزون عام (القرار 3) بحركة مستقلة.
   542→          if (residual > _qtyEpsilon) {
   543→            await txn.insert('stock_movement', {
   544→              'product_id': productId,
   545→              'warehouse_id': orig.row['warehouse_id'],
   546→              'movement_type': 'sale_return',
   547→              'qty': residual,
   548→              'unit_cost': snapshotUnit,
   549→              'ref_type': 'invoice',
   550→              'ref_id': invoiceId,
   551→              'moved_at': issuedIso,
   552→              'notes': docNo,
   553→              'created_at': at.toUtc().toIso8601String(),
   554→              'created_by': userId,
   555→            });
   556→          }
   557→
   558→          // دفتر stock_level للنوعين — زيادة مباشرة.
   559→          await txn.rawInsert(
   560→            'INSERT OR IGNORE INTO stock_level(product_id, warehouse_id, qty)'
   561→            ' VALUES(?, ?, 0)',
   562→            [productId, orig.row['warehouse_id']],
   563→          );
   564→          await txn.rawUpdate(
   565→            'UPDATE stock_level SET qty = qty + ? '
   566→            'WHERE product_id = ? AND warehouse_id = ?',
   567→            [lineQty, productId, orig.row['warehouse_id']],
   568→          );
   569→        }
   570→
   571→        // 10-هـ) الجزء النقدي: سند **صرف** للعميل + تخصيص عكسي (القرار 2)
   572→        //        — customer_id = NULL حتى لا يُخصم من رصيد العميل مرتين.
   573→        if (refundCash > moneyEpsilon) {
   574→          final cashTxId = await txn.insert('cash_tx', {
   575→            'tx_type': 'payment',
   576→            'cashbox_id': cashboxId,
   577→            'currency_id': orig.row['currency_id'],
   578→            'amount': refundCash,
   579→            'exchange_rate': fx.rate,
   580→            'tx_date': issuedIso,
   581→            'ref_type': 'invoice',
   582→            'ref_id': invoiceId,
   583→            'customer_id': null, // لا يُخصم من رصيد العميل (القرار 2).
   584→            'description': 'إرجاع نقدي عند إصدار $docNo',
   585→            'created_at': at.toUtc().toIso8601String(),
   586→            'created_by': userId,
   587→          });
   588→          await txn.insert('payment_allocation', {
   589→            'cash_tx_id': cashTxId,
   590→            'invoice_id': invoiceId,
   591→            'allocated_amount': refundCash,
   592→            'allocated_at': at.toUtc().toIso8601String(),
   593→            'created_by': userId,
   594→          });
   595→        }
   596→        // الجزء المخصوم من الحساب لا يُدرج في payment_allocation — دينه في
   597→        // invoice.due_amount للمستند المرتجع تطرحه صيغة رصيد العميل
   598→        // (FR-03-02) وكشف الحساب يظهره قيداً سالباً.
   599→
   600→        // 10-و) قيد التدقيق.
   601→        await txn.insert('audit_log', {
   602→          'user_id': userId,
   603→          'action': 'sale_return_post',
   604→          'entity': 'invoice',
   605→          'entity_id': invoiceId,
   606→          'details':
   607→              'no=$docNo original=${orig.row['invoice_no']} '
   608→              'total=$refundTotal cash=$refundCash credit=$refundCredit '
   609→              'currency=${orig.row['currency_id']} rate=${fx.rate}'
   610→              '${fx.isFallback ? ' fallback=1' : ''}',
   611→          'at': at.toUtc().toIso8601String(),
   612→        });
   613→
   614→        return Ok<ReturnPostedReceipt, String>(
   615→          ReturnPostedReceipt(
   616→            invoiceId: invoiceId,
   617→            docNo: docNo,
   618→            docType: 'SRN',
   619→            originalInvoiceId: draft.originalInvoiceId,
   620→            originalInvoiceNo: orig.row['invoice_no'] as String?,
   621→            refundTotal: refundTotal,
   622→            refundCash: refundCash,
   623→            refundCredit: refundCredit,
   624→            payStatus: settlement.method,
   625→            exchangeRate: fx.rate,
   626→            rateIsFallback: fx.isFallback,
   627→          ),
   628→        );
   629→      });
   630→    } on _FlowError catch (e) {
   631→      return Err(e.message);
   632→    } on StateError catch (e) {
   633→      return Err(e.message);
   634→    } on DatabaseException catch (e) {
   635→      return Err(_describeDbError(e));
   636→    }
   637→  }

   640→  // مرتجع الشراء (PRN) — FR-02-08
   641→  // ───────────────────────────────────────────────────────────────────
   642→
   643→  /// **ترحيل مرتجع شراء مرتبط** — معاملة واحدة (انظر رأس الملف).
   644→  ///
   645→  /// الكمية تخرج من مخزن الفاتورة الأصلية **بسعر حركة الشراء الأصلية
   646→  /// (Snapshot)** من الدفعة الواردة أولاً (القرار 4)، وWAC يُعاد حسابه
   647→  /// على المتبقي (قاعدة 5.4-3)، والقيمة تُسترد نقداً إلى الصندوق أو خصماً
   648→  /// من دين المورد (القرار 2).
   649→  Future<Result<ReturnPostedReceipt, String>> postPurchaseReturn(
   650→    PurchaseReturnDraft draft, {
   651→    required int userId,
   652→    DateTime? now,
   653→  }) async {
   654→    final at = now ?? DateTime.now();
   655→    final issuedAt = draft.issuedAt;
   656→    final issuedIso = issuedAt.toUtc().toIso8601String();
   657→
   658→    // (1) تحقق نقي من البنود.
   659→    final linesFailure = _validateLines(draft.lines);
   660→    if (linesFailure != null) return Err(linesFailure);
   661→
   662→    try {
   663→      // (2) الفاتورة الأصلية: نوع + حالة + وجود.
   664→      final orig = await _loadOriginal(draft.originalInvoiceId, 'purchase');
   665→      if (orig.error != null) return Err(orig.error!);
   666→
   667→      // (3) البنود + المنتسب + السقف (المشترى − المرتجع سابقاً).
   668→      final membership = await _checkMembershipAndCaps(
   669→        draft.originalInvoiceId,
   670→        'purchase_return',
   671→        draft.lines,
   672→      );
   673→      if (membership.error != null) return Err(membership.error!);
   674→      final origItems = membership.items;
   675→
   676→      // (4) قيمة الاسترداد Snapshot (القرار 6).
   677→      final valued = _valueReturnLines(origItems, draft.lines);
   678→      final refundTotal = valued.refundTotal;
   679→
   680→      // (5) اتجاه الرد (القرار 2).
   681→      final refundFailure = _validateRefund(
   682→        refundTotal,
   683→        draft.refundCash,
   684→        draft.refundMethod,
   685→      );
   686→      if (refundFailure != null) return Err(refundFailure);
   687→      final settlement = _settleRefund(refundTotal, draft.refundCash);
   688→      final refundCash = settlement.netCash;
   689→      final refundCredit = settlement.credit;
   690→
   691→      // (6) المورد للجزء المخصوم من دينه.
   692→      if (refundCredit > moneyEpsilon && orig.row['supplier_id'] == null) {
   693→        return Err(
   694→          'فاتورة الشراء الأصلية بلا مورد مسجَّل — لا حساب يُخصم منه؛ '
   695→          'اختر الاسترداد نقداً إلى الصندوق.',
   696→        );
   697→      }
   698→
   699→      // (7) سياسة FX بعملة الفاتورة الأصلية بتاريخ المرتجع (القرار 5).
   700→      final fx = await _resolveRate(orig.row['currency_id'] as int, issuedAt);
   701→      if (fx.error != null) return Err(fx.error!);
   702→
   703→      // (8) الصندوق الافتراضي — للجزء النقدي فقط.
   704→      int? cashboxId;
   705→      if (refundCash > moneyEpsilon) {
   706→        final boxId = await _defaultCashboxId();
   707→        if (boxId == null) {
   708→          return Err('لا يوجد صندوق افتراضي للمنشأة — أنشئ صندوقاً أولاً.');
   709→        }
   710→        cashboxId = boxId;
   711→      }
   712→
   713→      // (9) معلومات الأصناف + فحص توفر المخزون مسبقاً (5.4-5).
   714→      final products = await _loadProductsForItems(origItems);
   715→      final stockFailure = await _checkReturnStock(
   716→        origItems,
   717→        products,
   718→        draft.lines,
   719→        orig.row['warehouse_id'] as int,
   720→      );
   721→      if (stockFailure != null) return Err(stockFailure);
   722→
   723→      // (10) المعاملة الواحدة — كل الكتابات أو لا شيء (5.4-4).
   724→      return await _db.transaction((txn) async {
   725→        // 10-أ) رقم PRN ذرّي (قاعدة 5.4-1).
   726→        final year = issuedAt.year;
   727→        final seq = DocSequenceService(txn);
   728→        final number = await seq.nextNumber(
   729→          DocSequenceType.purchaseReturn,
   730→          year,
   731→        );
   732→        final docNo = formatDocNumber(
   733→          DocSequenceType.purchaseReturn,
   734→          year,
   735→          number,
   736→        );
   737→
   738→        // 10-ب) رأس المرتجع — الارتباط الحصري بالمورد الأصلي.
   739→        final invoiceId = await txn.insert('invoice', {
   740→          'invoice_no': docNo,
   741→          'doc_type': 'purchase_return',
   742→          'pay_status': settlement.method.code,
   743→          'status': 'completed',
   744→          'issued_at': issuedIso,
   745→          'original_invoice_id': draft.originalInvoiceId,
   746→          'supplier_id': orig.row['supplier_id'],
   747→          'cashbox_id': cashboxId,
   748→          'warehouse_id': orig.row['warehouse_id'],
   749→          'currency_id': orig.row['currency_id'],
   750→          'exchange_rate': fx.rate,
   751→          'rate_is_fallback': fx.isFallback ? 1 : 0,
   752→          'subtotal': valued.subtotal,
   753→          'discount_amount': valued.discountTotal,
   754→          'tax_rate': 0,
   755→          'tax_amount': 0,
   756→          'total': refundTotal,
   757→          'total_base': roundCost(refundTotal * fx.rate),
   758→          'paid_amount': refundCash,
   759→          'due_amount': refundCredit,
   760→          'cost_total': valued.costTotal,
   761→          'notes_internal': draft.notesInternal,
   762→          'notes_printed': draft.notesPrinted,
   763→          'created_at': at.toUtc().toIso8601String(),
   764→          'updated_at': at.toUtc().toIso8601String(),
   765→          'created_by': userId,
   766→        });
   767→
   768→        // 10-ج) حراسة السقف داخل المعاملة.
   769→        await _assertCapsInside(
   770→          txn,
   771→          draft.originalInvoiceId,
   772→          'purchase_return',
   773→          draft.lines,
   774→        );
   775→
   776→        // 10-د) البنود: خروج Snapshot + خصم الدفعات + إعادة حساب WAC.
   777→        for (var i = 0; i < draft.lines.length; i++) {
   778→          final input = draft.lines[i];
   779→          final origItem = origItems[input.invoiceItemId]!;
   780→          final productId = origItem['product_id'] as int?;
   781→          final info = productId == null ? null : products[productId];
   782→          final lineQty = input.qty;
   783→
   784→          // Snapshot تكلفة الوحدة الأصلية (بالعملة الأساسية) — مقسوم
   785→          // المستلم الكلي (R16-a: بونص الشراء داخل line_cost — القسمة
   786→          // على qty + free_qty تعيد تكلفة الوحدة الفعلية وقت الشراء).
   787→          final snapshotUnit = roundCost(
   788→            (origItem['line_cost'] as num? ?? 0) / _dispatchedDivisor(origItem),
   789→          );
   790→          final lineCost = roundCost(lineQty * snapshotUnit);
   791→
   792→          // WAC قبل الخصم: يُقرأ المخزون الكلي والتكلفة داخل المعاملة.
   793→          final wacBefore =
   794→              (info == null || info.isService || productId == null)
   795→              ? null
   796→              : await _readWacState(txn, productId);
   797→
   798→          // خصم الدفعات (القرار 4): الواردة الأصلية أولاً ثم FEFO للمتبقي.
   799→          final deductions = <_BatchCap>[];
   800→          if (info != null && info.trackBatches && productId != null) {
   801→            var remaining = lineQty;
   802→            // الواردة الأصلية (بمعرّفها المخزَّن وقت الشراء) — خصم محروس.
   803→            final originalBatchId = origItem['batch_id'] as int?;
   804→            if (originalBatchId != null) {
   805→              final batchRows = await txn.query(
   806→                'batch',
   807→                columns: ['id', 'batch_number', 'expiry_date', 'qty'],
   808→                where: 'id = ?',
   809→                whereArgs: [originalBatchId],

   814→                    (batchRows.first['qty'] as num?)?.toDouble() ?? 0;

   818→                    'UPDATE batch SET qty = qty - ?, updated_at = ? '
   819→                    'WHERE id = ? AND qty >= ?',
   820→                    [take, at.toUtc().toIso8601String(), originalBatchId, take],

   824→                      _BatchCap(
   825→                        batchId: originalBatchId,
   826→                        batchNumber: batchRows.first['batch_number'] as String,
   827→                        expiryDate: batchRows.first['expiry_date'] as String,
   828→                        qty: take,
   829→                      ),
   830→                    );
   831→                    remaining = roundCost(remaining - take);
   832→                  }
   833→                }
   834→              }
   835→            }

   837→            // للمورد جائز) — أحراس السالب بداخلها ترمي فتتراجع المعاملة.

   853→                );
   854→              }

   870→              ? null

  1272→  /// line_total = gross − الخصم — والتكلفة الأصلية منقولة تناسبياً
  1273→  /// **بتكلفة الوحدة على المنصرف الكلي** (البونص داخل line_cost —
  1274→  /// القرار 8 برأس الملف).
  1275→  _ValuedReturn _valueReturnLines(
  1276→    Map<int, Map<String, Object?>> origItems,
  1277→    List<ReturnLineInput> lines,
  1278→  ) {
  1279→    var subtotal = 0.0;
  1280→    var discountTotal = 0.0;
  1281→    var refundTotal = 0.0;
  1282→    var costTotal = 0.0;
  1283→    final lineTotals = <double>[];
  1284→    final discounts = <double>[];
  1285→    for (final line in lines) {
  1286→      final item = origItems[line.invoiceItemId]!;
  1287→      final origQty = (item['qty'] as num?)?.toDouble() ?? 1;
  1288→      final unitPrice = (item['unit_price'] as num?)?.toDouble() ?? 0;
  1289→      final origDiscount = (item['discount_amount'] as num?)?.toDouble() ?? 0;
  1290→      final origLineCost = (item['line_cost'] as num?)?.toDouble() ?? 0;
  1291→
  1292→      final gross = roundMoney(line.qty * unitPrice);
  1293→      final discount = roundMoney(line.qty * origDiscount / origQty);
  1294→      final lineTotal = roundMoney(gross - discount);
  1295→      final lineCost = roundCost(
  1296→        line.qty * roundCost(origLineCost / _dispatchedDivisor(item)),
  1297→      );
  1298→
  1299→      lineTotals.add(lineTotal);
  1300→      discounts.add(discount);
  1301→      subtotal = roundMoney(subtotal + gross);
  1302→      discountTotal = roundMoney(discountTotal + discount);
  1303→      refundTotal = roundMoney(refundTotal + lineTotal);
  1304→      costTotal = roundCost(costTotal + lineCost);
  1305→    }
  1306→    return _ValuedReturn(
  1307→      subtotal: subtotal,
  1308→      discountTotal: discountTotal,
  1309→      refundTotal: refundTotal,
  1310→      costTotal: costTotal,
  1311→      lineTotals: lineTotals,
  1312→      discounts: discounts,
  1313→    );
  1314→  }

  1316→  /// يتحقق من اتجاه رد القيمة مقابل الأرقام (القرار 2) — مرآة نمط
  1317→  /// `PurchasePricing.validatePayment` بصياغة المرتجع.
  1318→  String? _validateRefund(
  1319→    double refundTotal,
  1320→    double refundCash,
  1321→    ReturnRefundMethod declared,
  1322→  ) {
  1323→    if (refundCash.isNaN || refundCash.isInfinite || refundCash < 0) {
  1324→      return 'المبلغ النقدي المرتجع لا يمكن أن يكون سالباً.';
  1325→    }
  1326→    if (refundCash > refundTotal + moneyEpsilon) {
  1327→      return 'المبلغ النقدي المرتجع ($refundCash) يتجاوز قيمة المرتجع '
  1328→          '($refundTotal) — المرتجع لا يقبل الرد الزائد؛ اترك الباقي على '
  1329→          'الحساب.';
  1330→    }
  1331→    final derived = _deriveMethod(refundTotal, refundCash);
  1332→    if (derived == declared) return null;
  1333→    switch (declared) {
  1334→      case ReturnRefundMethod.cash:
  1335→        return 'الرد النقدي يتطلب رد قيمة المرتجع كاملة نقداً '
  1336→            '($refundTotal) — أو اختر الخصم من الحساب/المختلط.';
  1337→      case ReturnRefundMethod.credit:
  1338→        return 'الخصم من الحساب يتطلب عدم إدخال أي مبلغ نقدي — المدخل '
  1339→            '$refundCash.';
  1340→      case ReturnRefundMethod.mixed:
  1341→        return 'الرد المختلط يتطلب مبلغاً نقدياً بين صفر وقيمة المرتجع '
  1342→            '($refundTotal) حصراً — المدخل $refundCash.';
  1343→    }
  1344→  }
  1345→
  1346→  /// يستنتج اتجاه الرد من الأرقام: نقدي عند رد الكامل، على الحساب عند
  1347→  /// الصفر، مختلط بينهما.
  1348→  ReturnRefundMethod _deriveMethod(double refundTotal, double refundCash) {
  1349→    if (refundCash <= moneyEpsilon) return ReturnRefundMethod.credit;
  1350→    if (refundCash >= refundTotal - moneyEpsilon) {
  1351→      return ReturnRefundMethod.cash;
  1352→    }
  1353→    return ReturnRefundMethod.mixed;
  1354→  }

  1356→  /// يفصل الرد: الجزء النقدي + الجزء المخصوم من حساب الطرف.
  1357→  ({double netCash, double credit, ReturnRefundMethod method}) _settleRefund(
  1358→    double refundTotal,
  1359→    double refundCash,
  1360→  ) {
  1361→    final netCash = roundMoney(
  1362→      refundCash < refundTotal ? refundCash : refundTotal,
  1363→    );
  1364→    final credit = roundMoney(refundTotal - netCash);
  1365→    return (
  1366→      netCash: netCash,
  1367→      credit: credit,
  1368→      method: _deriveMethod(refundTotal, refundCash),
  1369→    );
  1370→  }

  1537→  /// تذهب للمخزون العام عبر «المتبقي»).
  1538→  Future<List<_BatchCap>> _loadBatchReturnCaps(
  1539→    DatabaseExecutor txn, {
  1540→    required int productId,
  1541→    required int warehouseId,
  1542→    required int originalInvoiceId,
  1543→  }) async {
  1544→    // استهلاك البيع الأصلي لكل دفعة (حركة لكل دفعة برجوع للفاتورة).
  1545→    final saleMoves = await txn.rawQuery(
  1546→      'SELECT notes, qty FROM stock_movement '
  1547→      "WHERE movement_type = 'sale' AND ref_type = 'invoice' AND ref_id = ? "
  1548→      'AND product_id = ? AND warehouse_id = ? ORDER BY id ASC',
  1549→      [originalInvoiceId, productId, warehouseId],
  1550→    );
  1551→    // (رقم الدفعة، تاريخ الصلاحية) → الكمية المستهلكة.
  1552→    final consumed = <String, double>{};
  1553→    final order = <String>[];
  1554→    for (final move in saleMoves) {
  1555→      final match = _batchNotePattern.firstMatch(
  1556→        (move['notes'] as String?) ?? '',
  1557→      );
  1558→      if (match == null) continue; // حركة غير دفعية (مخزون عام).
  1559→      final key = '${match.group(1)!.trim()}|${match.group(2)!}';
  1560→      consumed[key] =
  1561→          (consumed[key] ?? 0) - ((move['qty'] as num?)?.toDouble() ?? 0);
  1562→      if (!order.contains(key)) order.add(key);
  1563→    }
  1564→    // ما أُعيد سابقاً لكل دفعة (حركات SRN مكتملة سابقة بنفس الصيغة).
  1565→    final priorMoves = await txn.rawQuery(
  1566→      'SELECT sm.notes AS notes, sm.qty AS qty FROM stock_movement sm '
  1567→      "WHERE sm.movement_type = 'sale_return' AND sm.ref_type = 'invoice' "
  1568→      'AND sm.ref_id IN (SELECT id FROM invoice '
  1569→      "  WHERE doc_type = 'sale_return' AND status = 'completed' "
  1570→      '    AND original_invoice_id = ?) '
  1571→      'AND sm.product_id = ? AND sm.warehouse_id = ?',
  1572→      [originalInvoiceId, productId, warehouseId],
  1573→    );
  1574→    final priorReturned = <String, double>{};
  1575→    for (final move in priorMoves) {
  1576→      final match = _batchNotePattern.firstMatch(
  1577→        (move['notes'] as String?) ?? '',
  1578→      );
  1579→      if (match == null) continue; // عودة سابقة بلا دفعة (مخزون عام).
  1580→      final key = '${match.group(1)!.trim()}|${match.group(2)!}';
  1581→      priorReturned[key] =
  1582→          (priorReturned[key] ?? 0) + ((move['qty'] as num?)?.toDouble() ?? 0);
  1583→    }
  1584→
  1585→    // السعة الفعالة لكل دفعة (بترتيب استهلاك FEFO الأصلي) مع مطابقة
  1586→    // الصف الحي — نفس ترتيب allocateFefo الأصلي (id ASC) عند التكرار.
  1587→    final caps = <_BatchCap>[];
  1588→    for (final key in order) {
  1589→      final effective = (consumed[key] ?? 0) - (priorReturned[key] ?? 0);
  1590→      if (effective <= _qtyEpsilon) continue;
  1591→      final parts = key.split('|');
  1592→      final batchRows = await txn.query(
  1593→        'batch',
  1594→        columns: ['id'],
  1595→        where:
  1596→            'product_id = ? AND warehouse_id = ? AND batch_number = ? '
  1597→            'AND expiry_date = ? AND is_archived = 0',
  1598→        whereArgs: [productId, warehouseId, parts[0], parts[1]],
  1599→        orderBy: 'id ASC',
  1600→        limit: 1,
  1601→      );
  1602→      if (batchRows.isEmpty) continue; // غير قابلة للتتبع → متبقٍ عام.
  1603→      caps.add(
  1604→        _BatchCap(
  1605→          batchId: batchRows.first['id'] as int,
  1606→          batchNumber: parts[0],
  1607→          expiryDate: parts[1],
  1608→          qty: effective,
  1609→        ),
  1610→      );
  1611→    }
  1612→    return caps;
  1613→  }
