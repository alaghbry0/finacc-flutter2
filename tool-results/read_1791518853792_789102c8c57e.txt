     1→/// محرك ترحيل المرتجعات المرتبطة الذرّي — SRN (مرتجع بيع، FR-02-07) و
     2→/// PRN (مرتجع شراء، FR-02-08) — جداول `invoice` (doc_type='sale_return'/
     3→/// 'purchase_return' مع `original_invoice_id`) / `invoice_item` / `batch` /
     4→/// `stock_level` / `stock_movement` / `cash_tx` / `payment_allocation`.
     5→///
     6→/// **الخريطة الملزمة** (قاعدة 5.4-4 + ملحق و): الحفظ = (رقم SRN/PRN ذرّي +
     7→/// الفاتورة المرتبطة + بنودها بكميات وتكاليف **Snapshot من الفاتورة
     8→/// الأصلية** + حركات المخزون + حركة الصندوق للجزء النقدي + التخصيص +
     9→/// قيد التدقيق) داخل **Transaction واحدة** — فشل أي خطوة يرجع الكل.
    10→///
    11→/// خطوط حمراء مطبَّقة هنا:
    12→/// - **الارتباط الحصري** (FR-02-07): لا مرتجع حر — `original_invoice_id`
    13→///   إلزامي، والنوع يجب أن يطابق (SRN عن فاتورة بيع، PRN عن فاتورة شراء)،
    14→///   والحالة `completed` حصراً (الملغاة `void` والمسودة `draft` مرفوضتان).
    15→/// - **مرتجع البيع بتكلفة line_cost الأصلية** (قاعدة 5.4-3): الكمية تعود
    16→///   للمخزون **بالتكلفة الأصلية المنقولة** — WAC الجاري لا يُلمس إطلاقاً.
    17→/// - **مرتجع الشراء بسعر حركة الشراء الأصلية (Snapshot)** (FR-02-08): الخروج
    18→///   بتكلفة الوحدة الأصلية (`line_cost الأصلي / الكمية`) ويُعاد حساب WAC
    19→///   على المتبقي: `WAC = (qty_old×cost_old − qty_ret×cost_snapshot) /
    20→///   (qty_old − qty_ret)` مع حماية القسمة (المتبقي ≤ 0 → التكلفة 0) وعدم
    21→///   السماح بتكلفة سالبة.
    22→/// - **سقف الكميات**: مجموع مرتجعات الفاتورة ≤ المباع/المشترى لكل بند —
    23→///   يفحص قبل المعاملة ويعاد فحصه داخلها (حراسة التزامن).
    24→/// - **منع السالب المخزوني** (5.4-5): PRN يرفض ما لا يغطيه المخزون
    25→///   (stock_level للعادي، ومجموع الدفعات للمتتبع) برسالة تسمّي الصنف.
    26→///
    27→/// ## قرارات موثقة (انظر worklog-parts/7-b.md للتفصيل):
    28→/// 1. **مرجع البند الأصلي**: المخطط المجمد بلا عمود `original_item_id` في
    29→///    `invoice_item` — يُخزَّن المرجع بعلامة قياسية موثَّقة داخل عمود
    30→///    `notes` بصيغة «أصل البند #معرّف» (يكتبها ويقرؤها هذا المحرك حصراً
    31→///    بتعبير نمطي ثابت) — أساس حساب «المتبقي للإرجاع» لكل بند. طلب عمود
    32→///    مخصص مسجَّل للمنسّق.
    33→/// 2. **اتجاه المبلغ** (FR-02-07/08): `credit` = خصم من حساب الطرف عبر
    34→///    `invoice.due_amount` للمستند المرتجع — صيغتا رصيد العميل (FR-03-02)
    35→///    والمورد (FR-03-03) تطرحان `due_amount` لمستندات المرتجع تلقائياً
    36→///    فتنقصان الدين بلا أي كتابة إضافية، وكشف الحساب يظهر قيد المرتجع
    37→///    (−) صحيحاً. `cash` = رد نقدي من/إلى الصندوق (`cash_tx` باتجاه معاكس
    38→///    للفاتورة الأصلية: SRN سند **صرف** للعميل، PRN سند **قبض** من
    39→///    المورد) + **تخصيص مدفوعات عكسي** (`payment_allocation` يوثّق الجزء
    40→///    النقدي المرتجع كما يوثّق نظيره وقت الإصدار). `mixed` بينهما. سند
    41→///    SRN النقدي يُكتب بـ `customer_id = NULL` وسند PRN النقدي بـ
    42→///    `supplier_id = NULL` — مرآة اصطلاح الإصدار (لا خصم مزدوج من رصيد
    43→///    الطرف). لا رد زائد: المبلغ النقدي محصور بين 0 وقيمة المرتجع.
    44→/// 3. **الدفعات في مرتجع البيع (SRN)**: الكمية تعود إلى **دفعات الفاتورة
    45→///    الأصلية نفسها** — يُتبَّع الاستهلاك الأصلي من حركات مخزون البيع
    46→///    (`stock_movement` بحركة لكل دفعة برجوع للفاتورة، وملاحظتها تحمل
    47→///    «رقم الدفعة X (تنتهي Y)» — نفس صيغة `sale_repository` حرفياً)،
    48→///    والسعة لكل دفعة = ما استُهلك منها في البيع الأصلي − ما أُعيد إليها
    49→///    سابقاً (حركات SRN سابقة بنفس الصيغة) — فلا تتجاوز كمية أي دفعة ما
    50→///    استُهلك منها أبداً، والبنود المتعددة لنفس الصنف في مرتجع واحد
    51→///    تتقاسم السعات في الذاكرة. **أي كمية متبقية بلا دفعة قابلة للتتبع
    52→///    (دفعة مؤرشفة/محذوفة أو استهلاك غير موثَّق) تضاف للمخزون العام بلا
    53→///    دفعة** مع تعليق موثَّق في ملاحظة السطر (وفق التكليف) — ملاحظة:
    54→///    رصيد المتتبعين بلا دفعة لا يظهر متاحاً للبيع (فحص توفر البيع يعدّ
    55→///    الدفعات النشطة فقط) حتى شراء لاحق بدفعة.
    56→/// 4. **الدفعات في مرتجع الشراء (PRN)**: الخصم من **الدفعة الواردة
    57→///    الأصلية** أولاً (`invoice_item.batch_id` الذي خزّنه postPurchase لكل
    58→///    بند) ثم أي متبقٍ بدفعات الصنف النشطة FEFO (`allocateFefo` بـ
    59→///    includeExpired — إرجاع البضاعة المنتهية للمورد جائز)؛ وإن لم تكفِ
    60→///    الدفعات فالعملية **تُرفض** (المتتبع مخزونه في دفعاته — خصم بلا
    61→///    دفعة يفسد نسبة الدفعات إلى stock_level).
    62→/// 5. **عملة المرتجع وسعره**: عملة المستند المرتجع = عملة الفاتورة
    63→///    الأصلية حصراً (حتى يخصم/يرد على الرصيد الصحيح بعملته — 5.4-7)،
    64→///    وسعر صرفه يُحل وفق FR-08-09 بتاريخ إصدار المرتجع (الرفض أو
    65→///    `fx.fallback` بعلم) — **قيمة المخزون لا تُحوَّل بسعر يوم المرتجع**
    66→///    بل تُنقل من `line_cost` الأصلي (Snapshot بالعملة الأساسية).
    67→/// 6. **مبلغ المرتجع**: لكل بند — `gross = round2(qty_ret × unit_price
    68→///    الأصلي)` وخصم تناسبي `round2(qty_ret × discount_amount الأصلي /
    69→///    qty الأصلية)` فـ `line_total = gross − الخصم` — استرداد تناسبي
    70→///    تام لما دُفع فعلاً عن الوحدات المرتجعة (بما فيها نصيبها من خصم
    71→///    الرأس الموزَّع وقت الشراء/البيع المخزَّن في `discount_amount`).
    72→/// 7. **المخزن**: حركات المرتجع على مخزن الفاتورة الأصلية حصراً (حيث
    73→///    خرجت/دخلت البضاعة أصلاً).

   285→/// مستودع المرتجعات — SRN وPRN المرتبطة حصراً + بنود الإرجاع المتاحة.
   286→class ReturnRepository {
   287→  /// يبنى فوق قاعدة مفتوحة؛ يركّب المستودعات الشريكة فوق نفس القاعدة.
   288→  ReturnRepository(Database db)
   289→    : _db = db,
   290→      _rates = ExchangeRateRepository(db),
   291→      _settings = SettingsRepository(db),
   292→      _batches = BatchRepository(db);
   293→
   294→  final Database _db;
   295→  final ExchangeRateRepository _rates;
   296→  final SettingsRepository _settings;
   297→  final BatchRepository _batches;
   298→
   299→  // ───────────────────────────────────────────────────────────────────
   300→  // مرتجع البيع (SRN) — FR-02-07
   301→  // ───────────────────────────────────────────────────────────────────
   302→
   303→  /// **ترحيل مرتجع بيع مرتبط** — معاملة واحدة (انظر رأس الملف).
   304→  ///
   305→  /// الكمية تعود لمخزن الفاتورة الأصلية **بتكلفة line_cost الأصلية**
   306→  /// (لا WAC الجاري — قاعدة 5.4-3) وإلى دفعات البيع الأصلية عند تتبعها
   307→  /// (القرار 3)، والقيمة تُرد نقداً من الصندوق أو خصماً من حساب العميل
   308→  /// (القرار 2).
   309→  Future<Result<ReturnPostedReceipt, String>> postSaleReturn(
   310→    SaleReturnDraft draft, {
   311→    required int userId,
   312→    DateTime? now,
   313→  }) async {
   314→    final at = now ?? DateTime.now();
   315→    final issuedAt = draft.issuedAt;
   316→    final issuedIso = issuedAt.toUtc().toIso8601String();
   317→
   318→    // (1) تحقق نقي من البنود — قبل أي قراءة/كتابة.
   319→    final linesFailure = _validateLines(draft.lines);
   320→    if (linesFailure != null) return Err(linesFailure);
   321→
   322→    try {
   323→      // (2) الفاتورة الأصلية: نوع + حالة + وجود (FR-02-07).
   324→      final orig = await _loadOriginal(draft.originalInvoiceId, 'sale');
   325→      if (orig.error != null) return Err(orig.error!);
   326→
   327→      // (3) البنود الأصلية + المنتسب + سقف الكميات (القرار 1).
   328→      final membership = await _checkMembershipAndCaps(
   329→        draft.originalInvoiceId,
   330→        'sale_return',
   331→        draft.lines,
   332→      );
   333→      if (membership.error != null) return Err(membership.error!);
   334→      final origItems = membership.items;
   335→
   336→      // (4) قيمة المرتجع Snapshot من البنود الأصلية (القرار 6).
   337→      final valued = _valueReturnLines(origItems, draft.lines);
   338→      final refundTotal = valued.refundTotal;
   339→
   340→      // (5) اتجاه الرد مقابل الأرقام (القرار 2).
   341→      final refundFailure = _validateRefund(
   342→        refundTotal,
   343→        draft.refundCash,
   344→        draft.refundMethod,
   345→      );
   346→      if (refundFailure != null) return Err(refundFailure);
   347→      final settlement = _settleRefund(refundTotal, draft.refundCash);
   348→      final refundCash = settlement.netCash;
   349→      final refundCredit = settlement.credit;
   350→
   351→      // (6) حساب العميل للجزء المخصوم (FR-02-07: اتجاه المبلغ).
   352→      if (refundCredit > moneyEpsilon && orig.row['customer_id'] == null) {
   353→        return Err(
   354→          'الفاتورة الأصلية بلا عميل مسجَّل (بيع نقدي مجهول) — لا حساب '
   355→          'يُخصم منه؛ اختر رد القيمة نقداً من الصندوق.',
   356→        );
   357→      }
   358→
   359→      // (7) سياسة FX بعملة الفاتورة الأصلية بتاريخ المرتجع (القرار 5).
   360→      final fx = await _resolveRate(orig.row['currency_id'] as int, issuedAt);
   361→      if (fx.error != null) return Err(fx.error!);
   362→
   363→      // (8) الصندوق الافتراضي — للجزء النقدي فقط.
   364→      int? cashboxId;
   365→      if (refundCash > moneyEpsilon) {
   366→        final boxId = await _defaultCashboxId();
   367→        if (boxId == null) {
   368→          return Err('لا يوجد صندوق افتراضي للمنشأة — أنشئ صندوقاً أولاً.');
   369→        }
   370→        cashboxId = boxId;
   371→      }
   372→
   373→      // (9) معلومات الأصناف (خدمي/متتبع).
   374→      final products = await _loadProductsForItems(origItems);
   375→
   376→      // (10) المعاملة الواحدة — كل الكتابات أو لا شيء (5.4-4).
   377→      return await _db.transaction((txn) async {
   378→        // 10-أ) رقم SRN ذرّي (قاعدة 5.4-1).
   379→        final year = issuedAt.year;
   380→        final seq = DocSequenceService(txn);
   381→        final number = await seq.nextNumber(DocSequenceType.saleReturn, year);
   382→        final docNo = formatDocNumber(DocSequenceType.saleReturn, year, number);
   383→
   384→        // 10-ب) رأس المرتجع (كل الأعمدة وفق §5.3) — الارتباط الحصري.
   385→        final invoiceId = await txn.insert('invoice', {
   386→          'invoice_no': docNo,
   387→          'doc_type': 'sale_return',
   388→          'pay_status': settlement.method.code,
   389→          'status': 'completed',
   390→          'issued_at': issuedIso,
   391→          'original_invoice_id': draft.originalInvoiceId,
   392→          'customer_id': orig.row['customer_id'],
   393→          'cashbox_id': cashboxId,
   394→          'warehouse_id': orig.row['warehouse_id'],
   395→          'currency_id': orig.row['currency_id'],
   396→          'exchange_rate': fx.rate,
   397→          'rate_is_fallback': fx.isFallback ? 1 : 0,
   398→          'subtotal': valued.subtotal,
   399→          'discount_amount': valued.discountTotal,
   400→          'tax_rate': 0,
   401→          'tax_amount': 0,
   402→          'total': refundTotal,
   403→          'total_base': roundCost(refundTotal * fx.rate),
   404→          'paid_amount': refundCash,
   405→          'due_amount': refundCredit,
   406→          'cost_total': valued.costTotal,
   407→          'notes_internal': draft.notesInternal,
   408→          'notes_printed': draft.notesPrinted,
   409→          'created_at': at.toUtc().toIso8601String(),
   410→          'updated_at': at.toUtc().toIso8601String(),
   411→          'created_by': userId,
   412→        });
   413→
   414→        // 10-ج) حرارة السقف داخل المعاملة (التزامن — القرار 1).
   415→        await _assertCapsInside(
   416→          txn,
   417→          draft.originalInvoiceId,
   418→          'sale_return',
   419→          draft.lines,
   420→        );
   421→
   422→        // 10-د) البنود: تكلفة أصلية منقولة + عودة الكمية للمخزون
   423→        //       (ودفعات البيع الأصلية — القرار 3). سعات الدفعات تُحمَّل
   424→        //       مرة لكل صنف وتتقاسمها البنود في الذاكرة.
   425→        final batchCaps = <int, List<_BatchCap>>{};
   426→        for (var i = 0; i < draft.lines.length; i++) {
   427→          final input = draft.lines[i];
   428→          final origItem = origItems[input.invoiceItemId]!;
   429→          final productId = origItem['product_id'] as int?;
   430→          final info = productId == null ? null : products[productId];
   431→          final lineQty = input.qty;
   432→
   433→          // Snapshot تكلفة الوحدة الأصلية (بالعملة الأساسية).
   434→          final snapshotUnit = roundCost(
   435→            (origItem['line_cost'] as num? ?? 0) /
   436→                (origItem['qty'] as num? ?? 1),
   437→          );
   438→          final lineCost = roundCost(lineQty * snapshotUnit);
   439→
   440→          // سعات دفعات الصنف (استهلاك البيع الأصلي − ما أُعيد سابقاً).
   441→          List<_BatchCap>? caps;
   442→          if (info != null && info.trackBatches && productId != null) {
   443→            var productCaps = batchCaps[productId];
   444→            if (productCaps == null) {
   445→              productCaps = await _loadBatchReturnCaps(
   446→                txn,
   447→                productId: productId,
   448→                warehouseId: orig.row['warehouse_id'] as int,
   449→                originalInvoiceId: draft.originalInvoiceId,
   450→              );
   451→              batchCaps[productId] = productCaps;
   452→            }
   453→            caps = productCaps;
   454→          }
   455→
   456→          // تخصيص عودة هذا البند على السعات.
   457→          final entries = <_BatchCap>[];
   458→          var remaining = lineQty;
   459→          if (caps != null) {
   460→            for (final cap in caps) {
   461→              if (remaining <= _qtyEpsilon) break;
   462→              if (cap.qty <= _qtyEpsilon) continue;
   463→              final take = cap.qty < remaining ? cap.qty : remaining;
   464→              entries.add(
   465→                _BatchCap(
   466→                  batchId: cap.batchId,
   467→                  batchNumber: cap.batchNumber,
   468→                  expiryDate: cap.expiryDate,
   469→                  qty: take,
   470→                ),
   471→              );
   472→              cap.qty = roundCost(cap.qty - take);
   473→              remaining = roundCost(remaining - take);
   474→            }
   475→          }
   476→          final residual = roundCost(remaining);
   477→
   478→          final batchSummary = entries.isEmpty
   479→              ? null
   480→              : entries
   481→                    .map((e) => '${e.batchNumber}×${_num(e.qty)}')
   482→                    .join('، ');
   483→          final lineNotes = [
   484→            'أصل البند #${input.invoiceItemId}',
   485→            if (batchSummary != null) 'دفعة: $batchSummary',
   486→            if (residual > _qtyEpsilon)
   487→              'مرتجع بلا دفعة (${_num(residual)} أضيف للمخزون العام)',
   488→          ].join(' — ');
   489→
   490→          await txn.insert('invoice_item', {
   491→            'invoice_id': invoiceId,
   492→            'product_id': productId,
   493→            'line_desc': origItem['line_desc'],
   494→            'qty': lineQty,
   495→            'unit_id': origItem['unit_id'],
   496→            'unit_factor': 1,
   497→            'unit_price': origItem['unit_price'],
   498→            'discount_percent': origItem['discount_percent'],
   499→            'discount_amount': valued.discounts[i],
   500→            'tax_percent': 0,
   501→            'line_total': valued.lineTotals[i],
   502→            'line_cost': lineCost, // التكلفة الأصلية منقولة (5.4-3).
   503→            'batch_id': entries.isNotEmpty ? entries.first.batchId : null,
   504→            'notes': lineNotes,
   505→            'created_at': at.toUtc().toIso8601String(),
   506→          });
   507→
   508→          // الخدمي: لا مخزون (FR-01-16).
   509→          if (info == null || info.isService || productId == null) continue;
   510→
   511→          // زيادة الدفعات + حركة لكل دفعة (القرار 3).
   512→          for (final entry in entries) {
   513→            await txn.rawUpdate(
   514→              'UPDATE batch SET qty = qty + ?, updated_at = ? WHERE id = ?',
   515→              [entry.qty, at.toUtc().toIso8601String(), entry.batchId],
   516→            );
   517→            await txn.insert('stock_movement', {
   518→              'product_id': productId,
   519→              'warehouse_id': orig.row['warehouse_id'],
   520→              'movement_type': 'sale_return',
   521→              'qty': entry.qty, // الوارد موجب.
   522→              'unit_cost': snapshotUnit,
   523→              'ref_type': 'invoice',
   524→              'ref_id': invoiceId,
   525→              'moved_at': issuedIso,
   526→              'notes':
   527→                  'رقم الدفعة ${entry.batchNumber} '
   528→                  '(تنتهي ${entry.expiryDate}) — $docNo',
   529→              'created_at': at.toUtc().toIso8601String(),
   530→              'created_by': userId,
   531→            });
   532→          }
   533→          // المتبقي بلا دفعة → مخزون عام (القرار 3) بحركة مستقلة.
   534→          if (residual > _qtyEpsilon) {
   535→            await txn.insert('stock_movement', {
   536→              'product_id': productId,
   537→              'warehouse_id': orig.row['warehouse_id'],
   538→              'movement_type': 'sale_return',
   539→              'qty': residual,
   540→              'unit_cost': snapshotUnit,
   541→              'ref_type': 'invoice',
   542→              'ref_id': invoiceId,
   543→              'moved_at': issuedIso,
   544→              'notes': docNo,
   545→              'created_at': at.toUtc().toIso8601String(),
   546→              'created_by': userId,
   547→            });
   548→          }
   549→
   550→          // دفتر stock_level للنوعين — زيادة مباشرة.
   551→          await txn.rawInsert(
   552→            'INSERT OR IGNORE INTO stock_level(product_id, warehouse_id, qty)'
   553→            ' VALUES(?, ?, 0)',
   554→            [productId, orig.row['warehouse_id']],
   555→          );
   556→          await txn.rawUpdate(
   557→            'UPDATE stock_level SET qty = qty + ? '
   558→            'WHERE product_id = ? AND warehouse_id = ?',
   559→            [lineQty, productId, orig.row['warehouse_id']],
   560→          );
   561→        }
   562→
   563→        // 10-هـ) الجزء النقدي: سند **صرف** للعميل + تخصيص عكسي (القرار 2)
   564→        //        — customer_id = NULL حتى لا يُخصم من رصيد العميل مرتين.
   565→        if (refundCash > moneyEpsilon) {
   566→          final cashTxId = await txn.insert('cash_tx', {
   567→            'tx_type': 'payment',
   568→            'cashbox_id': cashboxId,
   569→            'currency_id': orig.row['currency_id'],
   570→            'amount': refundCash,
   571→            'exchange_rate': fx.rate,
   572→            'tx_date': issuedIso,
   573→            'ref_type': 'invoice',
   574→            'ref_id': invoiceId,
   575→            'customer_id': null, // لا يُخصم من رصيد العميل (القرار 2).
   576→            'description': 'إرجاع نقدي عند إصدار $docNo',
   577→            'created_at': at.toUtc().toIso8601String(),
   578→            'created_by': userId,
   579→          });
   580→          await txn.insert('payment_allocation', {
   581→            'cash_tx_id': cashTxId,
   582→            'invoice_id': invoiceId,
   583→            'allocated_amount': refundCash,
   584→            'allocated_at': at.toUtc().toIso8601String(),
   585→            'created_by': userId,
   586→          });
   587→        }
   588→        // الجزء المخصوم من الحساب لا يُدرج في payment_allocation — دينه في
   589→        // invoice.due_amount للمستند المرتجع تطرحه صيغة رصيد العميل
   590→        // (FR-03-02) وكشف الحساب يظهره قيداً سالباً.
   591→
   592→        // 10-و) قيد التدقيق.
   593→        await txn.insert('audit_log', {
   594→          'user_id': userId,
   595→          'action': 'sale_return_post',
   596→          'entity': 'invoice',
   597→          'entity_id': invoiceId,
   598→          'details':
   599→              'no=$docNo original=${orig.row['invoice_no']} '
   600→              'total=$refundTotal cash=$refundCash credit=$refundCredit '
   601→              'currency=${orig.row['currency_id']} rate=${fx.rate}'
   602→              '${fx.isFallback ? ' fallback=1' : ''}',
   603→          'at': at.toUtc().toIso8601String(),
   604→        });
   605→
   606→        return Ok<ReturnPostedReceipt, String>(
   607→          ReturnPostedReceipt(
   608→            invoiceId: invoiceId,
   609→            docNo: docNo,
   610→            docType: 'SRN',
   611→            originalInvoiceId: draft.originalInvoiceId,
   612→            originalInvoiceNo: orig.row['invoice_no'] as String?,
   613→            refundTotal: refundTotal,
   614→            refundCash: refundCash,
   615→            refundCredit: refundCredit,
   616→            payStatus: settlement.method,
   617→            exchangeRate: fx.rate,
   618→            rateIsFallback: fx.isFallback,
   619→          ),
   620→        );
   621→      });
   622→    } on _FlowError catch (e) {
   623→      return Err(e.message);
   624→    } on StateError catch (e) {
   625→      return Err(e.message);
   626→    } on DatabaseException catch (e) {
   627→      return Err(_describeDbError(e));
   628→    }
   629→  }

   631→  // ───────────────────────────────────────────────────────────────────
   632→  // مرتجع الشراء (PRN) — FR-02-08
   633→  // ───────────────────────────────────────────────────────────────────
   634→
   635→  /// **ترحيل مرتجع شراء مرتبط** — معاملة واحدة (انظر رأس الملف).
   636→  ///
   637→  /// الكمية تخرج من مخزن الفاتورة الأصلية **بسعر حركة الشراء الأصلية
   638→  /// (Snapshot)** من الدفعة الواردة أولاً (القرار 4)، وWAC يُعاد حسابه
   639→  /// على المتبقي (قاعدة 5.4-3)، والقيمة تُسترد نقداً إلى الصندوق أو خصماً
   640→  /// من دين المورد (القرار 2).
   641→  Future<Result<ReturnPostedReceipt, String>> postPurchaseReturn(
   642→    PurchaseReturnDraft draft, {
   643→    required int userId,
   644→    DateTime? now,
   645→  }) async {
   646→    final at = now ?? DateTime.now();
   647→    final issuedAt = draft.issuedAt;
   648→    final issuedIso = issuedAt.toUtc().toIso8601String();
   649→
   650→    // (1) تحقق نقي من البنود.
   651→    final linesFailure = _validateLines(draft.lines);
   652→    if (linesFailure != null) return Err(linesFailure);
   653→
   654→    try {
   655→      // (2) الفاتورة الأصلية: نوع + حالة + وجود.
   656→      final orig = await _loadOriginal(draft.originalInvoiceId, 'purchase');
   657→      if (orig.error != null) return Err(orig.error!);
   658→
   659→      // (3) البنود + المنتسب + السقف (المشترى − المرتجع سابقاً).
   660→      final membership = await _checkMembershipAndCaps(
   661→        draft.originalInvoiceId,
   662→        'purchase_return',
   663→        draft.lines,
   664→      );
   665→      if (membership.error != null) return Err(membership.error!);
   666→      final origItems = membership.items;
   667→
   668→      // (4) قيمة الاسترداد Snapshot (القرار 6).
   669→      final valued = _valueReturnLines(origItems, draft.lines);
   670→      final refundTotal = valued.refundTotal;
   671→
   672→      // (5) اتجاه الرد (القرار 2).
   673→      final refundFailure = _validateRefund(
   674→        refundTotal,
   675→        draft.refundCash,
   676→        draft.refundMethod,
   677→      );
   678→      if (refundFailure != null) return Err(refundFailure);
   679→      final settlement = _settleRefund(refundTotal, draft.refundCash);
   680→      final refundCash = settlement.netCash;
   681→      final refundCredit = settlement.credit;
   682→
   683→      // (6) المورد للجزء المخصوم من دينه.
   684→      if (refundCredit > moneyEpsilon && orig.row['supplier_id'] == null) {
   685→        return Err(
   686→          'فاتورة الشراء الأصلية بلا مورد مسجَّل — لا حساب يُخصم منه؛ '
   687→          'اختر الاسترداد نقداً إلى الصندوق.',
   688→        );
   689→      }
   690→
   691→      // (7) سياسة FX بعملة الفاتورة الأصلية بتاريخ المرتجع (القرار 5).
   692→      final fx = await _resolveRate(orig.row['currency_id'] as int, issuedAt);
   693→      if (fx.error != null) return Err(fx.error!);
   694→
   695→      // (8) الصندوق الافتراضي — للجزء النقدي فقط.
   696→      int? cashboxId;
   697→      if (refundCash > moneyEpsilon) {
   698→        final boxId = await _defaultCashboxId();
   699→        if (boxId == null) {
   700→          return Err('لا يوجد صندوق افتراضي للمنشأة — أنشئ صندوقاً أولاً.');
   701→        }
   702→        cashboxId = boxId;
   703→      }
   704→
   705→      // (9) معلومات الأصناف + فحص توفر المخزون مسبقاً (5.4-5).
   706→      final products = await _loadProductsForItems(origItems);
   707→      final stockFailure = await _checkReturnStock(
   708→        origItems,
   709→        products,
   710→        draft.lines,
   711→        orig.row['warehouse_id'] as int,
   712→      );
   713→      if (stockFailure != null) return Err(stockFailure);
   714→
   715→      // (10) المعاملة الواحدة — كل الكتابات أو لا شيء (5.4-4).
   716→      return await _db.transaction((txn) async {
   717→        // 10-أ) رقم PRN ذرّي (قاعدة 5.4-1).
   718→        final year = issuedAt.year;
   719→        final seq = DocSequenceService(txn);
   720→        final number = await seq.nextNumber(
   721→          DocSequenceType.purchaseReturn,
   722→          year,
   723→        );
   724→        final docNo = formatDocNumber(
   725→          DocSequenceType.purchaseReturn,
   726→          year,
   727→          number,
   728→        );
   729→
   730→        // 10-ب) رأس المرتجع — الارتباط الحصري بالمورد الأصلي.
   731→        final invoiceId = await txn.insert('invoice', {
   732→          'invoice_no': docNo,
   733→          'doc_type': 'purchase_return',
   734→          'pay_status': settlement.method.code,
   735→          'status': 'completed',
   736→          'issued_at': issuedIso,
   737→          'original_invoice_id': draft.originalInvoiceId,
   738→          'supplier_id': orig.row['supplier_id'],
   739→          'cashbox_id': cashboxId,
   740→          'warehouse_id': orig.row['warehouse_id'],
   741→          'currency_id': orig.row['currency_id'],
   742→          'exchange_rate': fx.rate,
   743→          'rate_is_fallback': fx.isFallback ? 1 : 0,
   744→          'subtotal': valued.subtotal,
   745→          'discount_amount': valued.discountTotal,
   746→          'tax_rate': 0,
   747→          'tax_amount': 0,
   748→          'total': refundTotal,
   749→          'total_base': roundCost(refundTotal * fx.rate),
   750→          'paid_amount': refundCash,
   751→          'due_amount': refundCredit,
   752→          'cost_total': valued.costTotal,
   753→          'notes_internal': draft.notesInternal,
   754→          'notes_printed': draft.notesPrinted,
   755→          'created_at': at.toUtc().toIso8601String(),
   756→          'updated_at': at.toUtc().toIso8601String(),
   757→          'created_by': userId,
   758→        });
   759→
   760→        // 10-ج) حراسة السقف داخل المعاملة.
   761→        await _assertCapsInside(
   762→          txn,
   763→          draft.originalInvoiceId,
   764→          'purchase_return',
   765→          draft.lines,
   766→        );
   767→
   768→        // 10-د) البنود: خروج Snapshot + خصم الدفعات + إعادة حساب WAC.
   769→        for (var i = 0; i < draft.lines.length; i++) {
   770→          final input = draft.lines[i];
   771→          final origItem = origItems[input.invoiceItemId]!;
   772→          final productId = origItem['product_id'] as int?;
   773→          final info = productId == null ? null : products[productId];
   774→          final lineQty = input.qty;
   775→
   776→          // Snapshot تكلفة الوحدة الأصلية (بالعملة الأساسية).
   777→          final snapshotUnit = roundCost(
   778→            (origItem['line_cost'] as num? ?? 0) /
   779→                (origItem['qty'] as num? ?? 1),
   780→          );
   781→          final lineCost = roundCost(lineQty * snapshotUnit);
   782→
   783→          // WAC قبل الخصم: يُقرأ المخزون الكلي والتكلفة داخل المعاملة.
   784→          final wacBefore =
   785→              (info == null || info.isService || productId == null)
   786→              ? null
   787→              : await _readWacState(txn, productId);
   788→
   789→          // خصم الدفعات (القرار 4): الواردة الأصلية أولاً ثم FEFO للمتبقي.
   790→          final deductions = <_BatchCap>[];
   791→          if (info != null && info.trackBatches && productId != null) {
   792→            var remaining = lineQty;
   793→            // الواردة الأصلية (بمعرّفها المخزَّن وقت الشراء) — خصم محروس.
   794→            final originalBatchId = origItem['batch_id'] as int?;
   795→            if (originalBatchId != null) {
   796→              final batchRows = await txn.query(
   797→                'batch',
   798→                columns: ['id', 'batch_number', 'expiry_date', 'qty'],
   799→                where: 'id = ?',
   800→                whereArgs: [originalBatchId],
   801→                limit: 1,
   802→              );
   803→              if (batchRows.isNotEmpty) {
   804→                final available =
   805→                    (batchRows.first['qty'] as num?)?.toDouble() ?? 0;
   806→                final take = available < remaining ? available : remaining;
   807→                if (take > _qtyEpsilon) {
   808→                  final affected = await txn.rawUpdate(
   809→                    'UPDATE batch SET qty = qty - ?, updated_at = ? '
   810→                    'WHERE id = ? AND qty >= ?',
   811→                    [take, at.toUtc().toIso8601String(), originalBatchId, take],
   812→                  );
   813→                  if (affected > 0) {
   814→                    deductions.add(
   815→                      _BatchCap(
   816→                        batchId: originalBatchId,
   817→                        batchNumber: batchRows.first['batch_number'] as String,
   818→                        expiryDate: batchRows.first['expiry_date'] as String,
   819→                        qty: take,
   820→                      ),
   821→                    );
   822→                    remaining = roundCost(remaining - take);
   823→                  }
   824→                }
   825→              }
   826→            }
   827→            // المتبقي بدفعات الصنف النشطة FEFO (المنتهية مشمولة — إرجاعها
   828→            // للمورد جائز) — أحراس السالب بداخلها ترمي فتتراجع المعاملة.

   861→              ? null

  1259→  /// قيمة بنود المرتجع Snapshot من البنود الأصلية (القرار 6):
  1260→  /// gross = round2(qty_ret × unit_price الأصلي)، خصم تناسبي،
  1261→  /// line_total = gross − الخصم — والتكلفة الأصلية منقولة تناسبياً.
  1262→  _ValuedReturn _valueReturnLines(
  1263→    Map<int, Map<String, Object?>> origItems,
  1264→    List<ReturnLineInput> lines,
  1265→  ) {
  1266→    var subtotal = 0.0;
  1267→    var discountTotal = 0.0;
  1268→    var refundTotal = 0.0;
  1269→    var costTotal = 0.0;
  1270→    final lineTotals = <double>[];
  1271→    final discounts = <double>[];
  1272→    for (final line in lines) {
  1273→      final item = origItems[line.invoiceItemId]!;
  1274→      final origQty = (item['qty'] as num?)?.toDouble() ?? 1;
  1275→      final unitPrice = (item['unit_price'] as num?)?.toDouble() ?? 0;
  1276→      final origDiscount = (item['discount_amount'] as num?)?.toDouble() ?? 0;
  1277→      final origLineCost = (item['line_cost'] as num?)?.toDouble() ?? 0;
  1278→
  1279→      final gross = roundMoney(line.qty * unitPrice);
  1280→      final discount = roundMoney(line.qty * origDiscount / origQty);
  1281→      final lineTotal = roundMoney(gross - discount);
  1282→      final lineCost = roundCost(line.qty * roundCost(origLineCost / origQty));
  1283→
  1284→      lineTotals.add(lineTotal);
  1285→      discounts.add(discount);
  1286→      subtotal = roundMoney(subtotal + gross);
  1287→      discountTotal = roundMoney(discountTotal + discount);
  1288→      refundTotal = roundMoney(refundTotal + lineTotal);
  1289→      costTotal = roundCost(costTotal + lineCost);
  1290→    }
  1291→    return _ValuedReturn(
  1292→      subtotal: subtotal,

  1301→  /// يتحقق من اتجاه رد القيمة مقابل الأرقام (القرار 2) — مرآة نمط
  1302→  /// `PurchasePricing.validatePayment` بصياغة المرتجع.
  1303→  String? _validateRefund(
  1304→    double refundTotal,
  1305→    double refundCash,
  1306→    ReturnRefundMethod declared,
  1307→  ) {
  1308→    if (refundCash.isNaN || refundCash.isInfinite || refundCash < 0) {
  1309→      return 'المبلغ النقدي المرتجع لا يمكن أن يكون سالباً.';
  1310→    }
  1311→    if (refundCash > refundTotal + moneyEpsilon) {
  1312→      return 'المبلغ النقدي المرتجع ($refundCash) يتجاوز قيمة المرتجع '
  1313→          '($refundTotal) — المرتجع لا يقبل الرد الزائد؛ اترك الباقي على '
  1314→          'الحساب.';
  1315→    }
  1316→    final derived = _deriveMethod(refundTotal, refundCash);
  1317→    if (derived == declared) return null;
  1318→    switch (declared) {
  1319→      case ReturnRefundMethod.cash:
  1320→        return 'الرد النقدي يتطلب رد قيمة المرتجع كاملة نقداً '
  1321→            '($refundTotal) — أو اختر الخصم من الحساب/المختلط.';
  1322→      case ReturnRefundMethod.credit:
  1323→        return 'الخصم من الحساب يتطلب عدم إدخال أي مبلغ نقدي — المدخل '
  1324→            '$refundCash.';
  1325→      case ReturnRefundMethod.mixed:
  1326→        return 'الرد المختلط يتطلب مبلغاً نقدياً بين صفر وقيمة المرتجع '
  1327→            '($refundTotal) حصراً — المدخل $refundCash.';
  1328→    }
  1329→  }
  1330→
  1331→  /// يستنتج اتجاه الرد من الأرقام: نقدي عند رد الكامل، على الحساب عند
  1332→  /// الصفر، مختلط بينهما.
  1333→  ReturnRefundMethod _deriveMethod(double refundTotal, double refundCash) {
  1334→    if (refundCash <= moneyEpsilon) return ReturnRefundMethod.credit;
  1335→    if (refundCash >= refundTotal - moneyEpsilon) {
  1336→      return ReturnRefundMethod.cash;
  1337→    }
  1338→    return ReturnRefundMethod.mixed;
  1339→  }

  1341→  /// يفصل الرد: الجزء النقدي + الجزء المخصوم من حساب الطرف.
  1342→  ({double netCash, double credit, ReturnRefundMethod method}) _settleRefund(
  1343→    double refundTotal,
  1344→    double refundCash,
  1345→  ) {
  1346→    final netCash = roundMoney(
  1347→      refundCash < refundTotal ? refundCash : refundTotal,
  1348→    );
  1349→    final credit = roundMoney(refundTotal - netCash);
  1350→    return (
  1351→      netCash: netCash,
  1352→      credit: credit,
  1353→      method: _deriveMethod(refundTotal, refundCash),
  1354→    );
  1355→  }

  1357→  /// يحل سعر الصرف وفق FR-08-09 (نفس نمط البيع/الشراء حرفياً).
  1358→  Future<({double rate, bool isFallback, String? error})> _resolveRate(
  1359→    int currencyId,
  1360→    DateTime issuedAt,
  1361→  ) async {
  1362→    final currencyRows = await _db.query(
  1363→      'currency',
  1364→      columns: ['code', 'is_base'],
  1365→      where: 'id = ?',
  1366→      whereArgs: [currencyId],
  1367→      limit: 1,
  1368→    );
  1369→    if (currencyRows.isEmpty) {
  1370→      return (rate: 1.0, isFallback: false, error: 'عملة الفاتورة غير موجودة.');
  1371→    }
  1372→    if ((currencyRows.first['is_base'] as int? ?? 0) == 1) {
  1373→      return (rate: 1.0, isFallback: false, error: null);
  1374→    }
  1375→    final code = currencyRows.first['code'] as String;
  1376→    final todayRate = await _rates.rateFor(currencyId, issuedAt);
  1377→    if (todayRate != null && todayRate > 0) {
  1378→      return (rate: todayRate, isFallback: false, error: null);
  1379→    }
  1380→    final fallbackOn =
  1381→        (await _settings.getString('fx.fallback', 'off')) == 'last_known';
  1382→    if (!fallbackOn) {
  1383→      return (
  1384→        rate: 1.0,
  1385→        isFallback: false,
  1386→        error:
  1387→            'لا يوجد سعر صرف لعملة $code بتاريخ اليوم — أدخل سعر اليوم '
  1388→            'أولاً ثم احفظ (لا يُحفظ بسعر افتراضي).',
  1389→      );
  1390→    }
  1391→    final lastKnown = await _rates.latestBefore(currencyId, issuedAt);
  1392→    if (lastKnown == null || lastKnown <= 0) {
  1393→      return (
  1394→        rate: 1.0,
  1395→        isFallback: false,
  1396→        error:
  1397→            'لا يوجد أي سعر صرف معروف لعملة $code — أدخل سعراً واحداً '
  1398→            'على الأقل قبل الحفظ بها.',
  1399→      );
  1400→    }
  1401→    return (rate: lastKnown, isFallback: true, error: null);
  1402→  }

  1441→  /// `stock_level` والمتتبع من مجموع دفعاته غير المؤرشفة.
  1442→  Future<String?> _checkReturnStock(
  1443→    Map<int, Map<String, Object?>> origItems,
  1444→    Map<int, _ReturnProductInfo> products,
  1445→    List<ReturnLineInput> lines,
  1446→    int warehouseId,
  1447→  ) async {
  1448→    final requested = <int, double>{};
  1449→    final names = <int, String>{};
  1450→    for (final line in lines) {
  1451→      final item = origItems[line.invoiceItemId]!;
  1452→      final productId = item['product_id'] as int?;
  1453→      if (productId == null) continue;
  1454→      final info = products[productId];
  1455→      if (info == null || info.isService) continue;
  1456→      requested[productId] = (requested[productId] ?? 0) + line.qty;
  1457→      names[productId] = info.name;
  1458→    }
  1459→    if (requested.isEmpty) return null;
  1460→    final ids = requested.keys.toList();
  1461→    final inClause = List.filled(ids.length, '?').join(',');
  1462→
  1463→    final plainRows = await _db.rawQuery(
  1464→      'SELECT product_id, qty FROM stock_level '
  1465→      'WHERE warehouse_id = ? AND product_id IN ($inClause)',
  1466→      [warehouseId, ...ids],
  1467→    );
  1468→    final plainQty = {
  1469→      for (final row in plainRows)
  1470→        row['product_id'] as int: (row['qty'] as num?)?.toDouble() ?? 0,
  1471→    };
  1472→    final batchRows = await _db.rawQuery(
  1473→      'SELECT product_id, SUM(qty) AS q FROM batch '
  1474→      'WHERE warehouse_id = ? AND product_id IN ($inClause) '
  1475→      '  AND qty > 0 AND is_archived = 0 GROUP BY product_id',
  1476→      [warehouseId, ...ids],
  1477→    );
  1478→    final batchQty = {
  1479→      for (final row in batchRows)
  1480→        row['product_id'] as int: (row['q'] as num?)?.toDouble() ?? 0,
  1481→    };
  1482→    for (final entry in requested.entries) {
  1483→      final tracked = products[entry.key]!.trackBatches;
  1484→      final available = tracked
  1485→          ? (batchQty[entry.key] ?? 0)
  1486→          : (plainQty[entry.key] ?? 0);
  1487→      if (available + _qtyEpsilon < entry.value) {
  1488→        return 'الكمية غير متوفرة للصنف «${names[entry.key]}»: المتاح '
  1489→            '${_num(available)} والمطلوب إرجاعه ${_num(entry.value)} — '
  1490→            'لا يسمح النظام بمخزون سالب.';
  1491→      }
  1492→    }
  1493→    return null;
  1494→  }

  1518→  /// **سعات عودة دفعات مرتجع البيع** (القرار 3): لكل دفعة استُهلكت في
  1519→  /// البيع الأصلي — السعة = ما استُهلك منها − ما أُعيد إليها سابقاً
  1520→  /// (حركات SRN سابقة بنفس صيغة الملاحظة)، مع مطابقة صف `batch` الحي
  1521→  /// بالرقم والتاريخ معاً؛ الدفعات غير القابلة للتتبع تُتخطى (كميتها
  1522→  /// تذهب للمخزون العام عبر «المتبقي»).
  1523→  Future<List<_BatchCap>> _loadBatchReturnCaps(
  1524→    DatabaseExecutor txn, {
  1525→    required int productId,
  1526→    required int warehouseId,
  1527→    required int originalInvoiceId,
  1528→  }) async {
  1529→    // استهلاك البيع الأصلي لكل دفعة (حركة لكل دفعة برجوع للفاتورة).
  1530→    final saleMoves = await txn.rawQuery(
  1531→      'SELECT notes, qty FROM stock_movement '
  1532→      "WHERE movement_type = 'sale' AND ref_type = 'invoice' AND ref_id = ? "
  1533→      'AND product_id = ? AND warehouse_id = ? ORDER BY id ASC',
  1534→      [originalInvoiceId, productId, warehouseId],
  1535→    );
  1536→    // (رقم الدفعة، تاريخ الصلاحية) → الكمية المستهلكة.
  1537→    final consumed = <String, double>{};
  1538→    final order = <String>[];
  1539→    for (final move in saleMoves) {
  1540→      final match = _batchNotePattern.firstMatch(
  1541→        (move['notes'] as String?) ?? '',
  1542→      );
  1543→      if (match == null) continue; // حركة غير دفعية (مخزون عام).
  1544→      final key = '${match.group(1)!.trim()}|${match.group(2)!}';
  1545→      consumed[key] =
  1546→          (consumed[key] ?? 0) - ((move['qty'] as num?)?.toDouble() ?? 0);
  1547→      if (!order.contains(key)) order.add(key);
  1548→    }
  1549→    // ما أُعيد سابقاً لكل دفعة (حركات SRN مكتملة سابقة بنفس الصيغة).
  1550→    final priorMoves = await txn.rawQuery(
  1551→      'SELECT sm.notes AS notes, sm.qty AS qty FROM stock_movement sm '
  1552→      "WHERE sm.movement_type = 'sale_return' AND sm.ref_type = 'invoice' "
  1553→      'AND sm.ref_id IN (SELECT id FROM invoice '
  1554→      "  WHERE doc_type = 'sale_return' AND status = 'completed' "
  1555→      '    AND original_invoice_id = ?) '
  1556→      'AND sm.product_id = ? AND sm.warehouse_id = ?',
  1557→      [originalInvoiceId, productId, warehouseId],
  1558→    );
  1559→    final priorReturned = <String, double>{};
  1560→    for (final move in priorMoves) {
  1561→      final match = _batchNotePattern.firstMatch(
  1562→        (move['notes'] as String?) ?? '',
  1563→      );
  1564→      if (match == null) continue; // عودة سابقة بلا دفعة (مخزون عام).
  1565→      final key = '${match.group(1)!.trim()}|${match.group(2)!}';
  1566→      priorReturned[key] =
  1567→          (priorReturned[key] ?? 0) + ((move['qty'] as num?)?.toDouble() ?? 0);
  1568→    }
  1569→
  1570→    // السعة الفعالة لكل دفعة (بترتيب استهلاك FEFO الأصلي) مع مطابقة
  1571→    // الصف الحي — نفس ترتيب allocateFefo الأصلي (id ASC) عند التكرار.
  1572→    final caps = <_BatchCap>[];
  1573→    for (final key in order) {
  1574→      final effective = (consumed[key] ?? 0) - (priorReturned[key] ?? 0);
  1575→      if (effective <= _qtyEpsilon) continue;
  1576→      final parts = key.split('|');
  1577→      final batchRows = await txn.query(
  1578→        'batch',
  1579→        columns: ['id'],
  1580→        where:
  1581→            'product_id = ? AND warehouse_id = ? AND batch_number = ? '
  1582→            'AND expiry_date = ? AND is_archived = 0',
  1583→        whereArgs: [productId, warehouseId, parts[0], parts[1]],
  1584→        orderBy: 'id ASC',
  1585→        limit: 1,
  1586→      );
  1587→      if (batchRows.isEmpty) continue; // غير قابلة للتتبع → متبقٍ عام.
  1588→      caps.add(
  1589→        _BatchCap(
  1590→          batchId: batchRows.first['id'] as int,
  1591→          batchNumber: parts[0],
  1592→          expiryDate: parts[1],
  1593→          qty: effective,
  1594→        ),
  1595→      );
  1596→    }
  1597→    return caps;
  1598→  }
